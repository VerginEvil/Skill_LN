# ProjectControl.SkipPrint

> Chapter: Chapter 55 Process Extensions
>
> Group: Process Extensions for ProjectControl
>
> Source: Infor LN Public Interfaces & Process Extensions Reference Guide (Cloud), pp. 2159-2159

Skips Projects when Printing Project Control Data. This process extension is available from 2019.09 ( KB2076283 ). To implement this process extension, you can use the information below:

```baan
Usage:        Process Extension ProjectControl.SkipPrint can be used to skip certain
Projects when Printing Project Control data.
Sessions where this Process Extension can be implemented:
-               Print Cost Control (tpppc4411m000)
-               Print Principals Project Control Report (tpppc4412m000)
-               Print Project Managers Control Report (tpppc4413m000)
-               Print Project Control (tpppc4420m000)
-               Print Management Report (tpppc4421m000)
Fields that are available to be used in this Process Extension:
-               All fields of table: Projects (tppdm600)
```
