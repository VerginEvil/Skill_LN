# ConfigurableItem.SkipCompileConstraints

> Chapter: Chapter 55 Process Extensions
>
> Group: Process Extensions for ConfigurableItem
>
> Source: Infor LN Public Interfaces & Process Extensions Reference Guide (Cloud), pp. 1995-1995

Skips Configurable Items when compiling constraints. This process extension is available from 2023.10 ( KB2296021 ). To implement this process extension, you can use the information below:

```baan
Usage:        Process Extension ConfigurableItem.SkipCompileConstraints can be used to
skip certain Configurable Items when requesting compilation of
constraints.
Sessions where this Process Extension can be implemented:
-               Compile Constraints by Configurable Item (tipcf2201m000)
Fields that are available to be used in this Process Extension:
-               tiipd001 - all fields
-               tcibd001 - all fields
```
