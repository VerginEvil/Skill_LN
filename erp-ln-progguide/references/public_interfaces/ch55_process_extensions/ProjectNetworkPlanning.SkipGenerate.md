# ProjectNetworkPlanning.SkipGenerate

> Chapter: Chapter 55 Process Extensions
>
> Group: Process Extensions for ProjectNetworkPlanning
>
> Source: Infor LN Public Interfaces & Process Extensions Reference Guide (Cloud), pp. 2182-2182

```baan
Skips Projects when Generating Network Planning in Project.
This process extension is available from 2019.09 (KB2076283).
To implement this process extension, you can use the information below:
Usage:        Process Extension ProjectNetworkPlanning.SkipGenerate can be used to
skip certain Projects when Generating Network Planning in Project.
Sessions where this Process Extension can be implemented:
- Generate Network Planning (tppss2240m000)
Fields that are available to be used in this Process Extension:
- All fields of table: Projects (tppdm600)
```
