# PurchaseOrderGenerate.SuppressCommingleLine

> Chapter: Chapter 55 Process Extensions
>
> Group: Process Extensions for PurchaseOrderGenerate
>
> Source: Infor LN Public Interfaces & Process Extensions Reference Guide (Cloud), pp. 2183-2184

Suppress commingling of purchase order lines when generating them. This process extension is available from 2022.10 ( KB2262990 ). Technical information for this process extension:

```baan
Usage:        With this Process Extension, it is possible to suppress commingling to
an existing purchase order line during generation of a new purchase
order line. This Process Extension is used in all flows were a purchase
order line is generated.
```
