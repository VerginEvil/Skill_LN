# Tools.SkipScrap

> Chapter: Chapter 55 Process Extensions
>
> Group: Process Extensions for Tools
>
> Source: Infor LN Public Interfaces & Process Extensions Reference Guide (Cloud), pp. 2308-2308

```baan
Skips specific tools when executing Scrap Tools Globally.
This process extension is available from 2023.10 (KB2308375).
To implement this process extension, you can use the information below:
Usage:        Process Extension Tools.SkipScrap can be used to skip scrapping of
specific tools.
Sessions where this Process Extension can be implemented:
- Scrap Tools Globally (titrp0202m000)
Fields that are available to be used in this Process Extension:
- titrp002.tltp  - titrp002.tnum - titrp002.cwar
```
