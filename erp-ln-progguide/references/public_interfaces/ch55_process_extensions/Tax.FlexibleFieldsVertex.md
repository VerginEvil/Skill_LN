# Tax.FlexibleFieldsVertex

> Chapter: Chapter 55 Process Extensions
>
> Group: Process Extensions for Tax
>
> Source: Infor LN Public Interfaces & Process Extensions Reference Guide (Cloud), pp. 2273-2273

Define Flexible Fields node to be used in call to Vertex. This process extension is available from 2023.10 ( KB2308375 ). Technical information for this process extension:

```baan
Usage:        With this Process Extension it is possible to expand the XML message to
the External Tax Provider (EXTP) with a 'flexible fields' node.
This 'flexible fields node' is used when the customer has defined some
customer specific tax rules in the External Tax Provider application.
Supported EXTP is Vertex.
```
