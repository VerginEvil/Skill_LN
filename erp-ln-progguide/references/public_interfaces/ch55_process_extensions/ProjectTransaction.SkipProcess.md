# ProjectTransaction.SkipProcess

> Chapter: Chapter 55 Process Extensions
>
> Group: Process Extensions for ProjectTransaction
>
> Source: Infor LN Public Interfaces & Process Extensions Reference Guide (Cloud), pp. 2189-2189

```baan
Skips Projects when Processing Transactions in Project.
This process extension is available from 2019.09 (KB2076283).
To implement this process extension, you can use the information below:
Usage:        Process Extension ProjectTransaction.SkipProcess can be used to skip
certain Projects when Processing Transactions in Project. This applies
to the following types of transactions:
- Costs
- Revenues
- Interim Results
- Project Completion
Sessions where this Process Extension can be implemented:
- Process Transactions (tpppc4802m000)
Fields that are available to be used in this Process Extension:
- All fields of table: Projects (tppdm600)
```
