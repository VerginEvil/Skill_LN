Determine customer specific tax country for Commissions and Rebates.
This process extension is available from 2025.12 (KB3635923).
Technical information for this process extension:
Usage:        With this Process Extension, it is possible to set a customer determined
tax country from an extension to a value other than the value that was
determined by standard LN logic.
This tax country is then used in the CMS invoicing flow, as well as
some master-data related sessions.
