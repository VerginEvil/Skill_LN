# ProductionOrder.SkipReportComplete

> Chapter: Chapter 55 Process Extensions
>
> Group: Process Extensions for ProductionOrder
>
> Source: Infor LN Public Interfaces & Process Extensions Reference Guide (Cloud), pp. 2165-2166

```baan
Skips Production Orders when Reporting Orders as Complete.
This process extension is available from 2021.03 (KB2175031).
To implement this process extension, you can use the information below:
Usage:        Process Extension ProductionOrder.SkipReportComplete can be used
to skip certain Production Orders when reporting a range of
Production Orders as complete.
Sessions where this Process Extension can be implemented:
- Report Orders Completed Globally (tisfc0206m000)
Fields that are available to be used in this Process Extension:
- All fields of table: Production Orders (tisfc001)
```
