# QualityNonConformance.SkipPrint

> Chapter: Chapter 55 Process Extensions
>
> Group: Process Extensions for QualityNonConformance
>
> Source: Infor LN Public Interfaces & Process Extensions Reference Guide (Cloud), pp. 2218-2218

```baan
Skips Printing of Non-Conformance Reports.
This process extension is available from 2019.09 (KB2076283).
To implement this process extension, you can use the information below:
Usage:        Process Extension QualityNonConformance.SkipPrint can be used to skip
certain Non-Conformance (Either Material or Non-Material) Reports
when Printing Non-Conformance Report.
Sessions where this Process Extension can be implemented:
- Print Non-Conformance Reports (qmncm1400m000)
Fields that are available to be used in this Process Extension:
- All fields of table: Non-Conformance Report (NCR) (qmncm100)
```
