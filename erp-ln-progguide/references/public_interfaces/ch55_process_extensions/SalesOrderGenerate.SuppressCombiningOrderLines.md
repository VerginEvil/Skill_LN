# SalesOrderGenerate.SuppressCombiningOrderLines

> Chapter: Chapter 55 Process Extensions
>
> Group: Process Extensions for SalesOrderGenerate
>
> Source: Infor LN Public Interfaces & Process Extensions Reference Guide (Cloud), pp. 2231-2231

Suppress combining of sales order lines when generating orders. This process extension is available from 2023.04 ( KB2286306 ). Technical information for this process extension:

```baan
Usage:        With this Process Extension, it is possible to suppress combining sales
order lines on the same sales order.
It is implemennd for generate processes that can create a new sales
order header.
```
