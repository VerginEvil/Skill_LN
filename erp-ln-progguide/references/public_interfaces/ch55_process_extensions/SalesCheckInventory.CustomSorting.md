# SalesCheckInventory.CustomSorting

> Chapter: Chapter 55 Process Extensions
>
> Group: Process Extensions for SalesCheckInventory
>
> Source: Infor LN Public Interfaces & Process Extensions Reference Guide (Cloud), pp. 2214-2214

Define a customer specific 'Sort Lines By' for Sales Check Inventory. This process extension is available from 2019.07 ( KB2066317 ). Technical information for this process extension:

```baan
Usage:        With this Process Extension, it is possible to set a customer defined
sorting from an extension. This sorting will be used in 'Check
Inventory for Sales Orders' (tdsls4217m000) when the 'Sort Lines
By' option 'Customer Defined' is selected.
```
