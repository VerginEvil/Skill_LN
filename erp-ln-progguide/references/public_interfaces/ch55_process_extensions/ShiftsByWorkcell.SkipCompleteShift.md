# ShiftsByWorkcell.SkipCompleteShift

> Chapter: Chapter 55 Process Extensions
>
> Group: Process Extensions for ShiftsByWorkcell
>
> Source: Infor LN Public Interfaces & Process Extensions Reference Guide (Cloud), pp. 2268-2268

```baan
Skips shifts based on Workcell when completing Shifts.
This process extension is available from 2022.02 (KB2198431).
To implement this process extension, you can use the information below:
Usage:        Process Extension ShiftsByWorkcell.SkipCompleteShift can be used to
skip certain Shifts when reporting a range of Shifts as complete.
Sessions where this Process Extension can be implemented:
- Complete Shifts (tirpt4236m000)
Fields that are available to be used in this Process Extension:
- All fields of table: Shifts by Work Cell (tirpt436)
```
