# PickingMission.HandleAfterGenerate

> Chapter: Chapter 55 Process Extensions
>
> Group: Process Extensions for PickingMission
>
> Source: Infor LN Public Interfaces & Process Extensions Reference Guide (Cloud), pp. 2104-2104

Allows to add functionality after the generation of a picking mission. This process extension is available from 2022.04 ( KB2235599 ). Technical information for this process extension:

```baan
Usage:        With this Process Extension it is possible execute actions
after the creation of a picking mission. This process extension will only
be triggered when the picking mission is generated, not when a reprint
or preview is done for the picking mission.
```
