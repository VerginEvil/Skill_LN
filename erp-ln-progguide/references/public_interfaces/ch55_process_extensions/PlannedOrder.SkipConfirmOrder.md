# PlannedOrder.SkipConfirmOrder

> Chapter: Chapter 55 Process Extensions
>
> Group: Process Extensions for PlannedOrder
>
> Source: Infor LN Public Interfaces & Process Extensions Reference Guide (Cloud), pp. 2106-2106

Skips planned orders to be confirmed. This process extension is available from 2026.01 ( KB3602370 ). To implement this process extension, you can use the information below:

```baan
Usage:
Process Extension PlannedOrder.SkipConfirmOrder can be used
to skip considering the planned orders to be confirmed.
Sessions where this Process Extension can be implemented:
-               Confirm Order Planning (cprrp1200m000)
Fields that are available to be used in this Process Extension:
-               All fields of table: Planned Orders (cprrp100)
```
