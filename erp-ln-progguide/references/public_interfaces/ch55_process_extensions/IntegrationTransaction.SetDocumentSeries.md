# IntegrationTransaction.SetDocumentSeries

> Chapter: Chapter 55 Process Extensions
>
> Group: Process Extensions for IntegrationTransaction
>
> Source: Infor LN Public Interfaces & Process Extensions Reference Guide (Cloud), pp. 2036-2036

Set document series during posting integration transactions. This process extension is available from 2026.09 ( KB3675398 ). Technical information for this process extension:

```baan
Usage:        With this Process Extension, it is possible for the extender to
influence the Series to be used for creating a Document during
Posting Integration Transactions. The Document Series can be overwritten
(io.document.series).
```
