# ExceptionMessagesByItem.SkipPrint

> Chapter: Chapter 55 Process Extensions
>
> Group: Process Extensions for ExceptionMessagesByItem
>
> Source: Infor LN Public Interfaces & Process Extensions Reference Guide (Cloud), pp. 2008-2008

Skips printing Exception Messages By Item. This process extension is available from 2023.05 ( KB2264479 ). To implement this process extension, you can use the information below:

```baan
Usage:        Process Extension ExceptionMessagesByItem.SkipPrint can be used
to skip printing.
Sessions where this Process Extension can be implemented:
-               Print Exception Messages by Planner and Item (cproa1425m000)
Fields that are available to be used in this Process Extension:
-                cprao020.*   (Exception Messages by Item)
-                tccom001.*   (Employees - General)
-                cprpd400.*   (Scenarios)
-                tcibd001.dsca
```
