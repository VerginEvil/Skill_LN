# QualityFailureDocument.SkipPrint

> Chapter: Chapter 55 Process Extensions
>
> Group: Process Extensions for QualityFailureDocument
>
> Source: Infor LN Public Interfaces & Process Extensions Reference Guide (Cloud), pp. 2192-2193

Skips Printing of FRACAS. This process extension is available from 2020.03 ( KB2111387 ). To implement this process extension, you can use the information below:

```baan
Usage:        Process Extension QualityFailureDocument.SkipPrint can be used to skip
certain FRACAS  Reports
when Printing Failure Document Report.
Sessions where this Process Extension can be implemented:
-               Print Failure Report Analysis and Corrective Action System
(qmpqm2400m000)
Fields that are available to be used in this Process Extension:
-               All fields of table: Failure Report Analysis and Corrective Action System
(qmpqm200)
Failure and Action Details(qmpqm201)
```
