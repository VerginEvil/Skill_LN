# PlannedInventoryTransaction.SkipPrint

> Chapter: Chapter 55 Process Extensions
>
> Group: Process Extensions for PlannedInventoryTransaction
>
> Source: Infor LN Public Interfaces & Process Extensions Reference Guide (Cloud), pp. 2105-2106

Skips printing of Planned Inventory Transaction. This process extension is available from 2025.04 ( KB3557494 ). To implement this process extension, you can use the information below:

```baan
Usage:        Process Extension PlannedInventoryTransaction.SkipPrint can be used
to skip the printing of Planned Inventory Transactions by Item.
Sessions where this Process Extension can be implemented:
-               Print Planned Inventory Transactions by Item (whinp1400m000)
Fields that are available to be used in this Process Extension:
-               All fields of tables:
-                       Planned Inventory Transactions by Item (whinp100)
```
