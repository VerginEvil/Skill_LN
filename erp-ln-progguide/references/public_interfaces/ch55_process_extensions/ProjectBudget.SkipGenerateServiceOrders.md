# ProjectBudget.SkipGenerateServiceOrders

> Chapter: Chapter 55 Process Extensions
>
> Group: Process Extensions for ProjectBudget
>
> Source: Infor LN Public Interfaces & Process Extensions Reference Guide (Cloud), pp. 2153-2153

Skips Projects when Generating Service Orders from a Project Budget. This process extension is available from 2019.09 ( KB2076283 ). To implement this process extension, you can use the information below:

```baan
Usage:        Process Extension ProjectBudget.SkipGenerateServiceOrders can be used
to skip certain Projects when Generating Service Orders from a Project
Budget.
Sessions where this Process Extension can be implemented:
-               Generate Service Orders (tppss6250m000)
Fields that are available to be used in this Process Extension:
-               All fields of table: Projects (tppdm600)
```
