# ProductionOrder.SkipPrintMaterialShortage

> Chapter: Chapter 55 Process Extensions
>
> Group: Process Extensions for ProductionOrder
>
> Source: Infor LN Public Interfaces & Process Extensions Reference Guide (Cloud), pp. 2165-2165

```baan
Skips shortages when printing.
This process extension is available from 2025.08 (KB3543720).
To implement this process extension, you can use the information below:
Usage:        Process Extension ProductionOrder.SkipPrintMaterialShortage can be used
to skip printing specific Material Shortages.
Sessions where this Process Extension can be implemented:
- Print Material Shortages by Production Order (tisfc0419m000)
Field that is available to be used in this Process Extension:
- timfc001.oorg (Order Origin)
- timfc001.pdno (Production Order)
- timfc001.pono (Position)
- timfc001.seqn (Sequence Number)
- timfc001.ittp (Transaction Type)
- timfc001.cwar (Warehouse)
```
