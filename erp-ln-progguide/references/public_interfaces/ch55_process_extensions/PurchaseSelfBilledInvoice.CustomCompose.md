Define a custom composing order for Purchase Self - Billing. This process extension is available from 2019.07 ( KB2064131 ). Technical information for this process extension:

```baan
Usage:        With this Process Extension, it is possible to set an own
custom compose criteria in the Self              -Billing Method.
The Purchase Self              -Billing (tfacp2290m000) process will compose
the invoices based on the defined custom composing criteria.
```
