# btext.nfe0001.modify.service.invoice.xml

> Chapter: Chapter 55 Process Extensions
>
> Group: Process Extensions for BrazilianInvoice
>
> Source: Infor LN Public Interfaces & Process Extensions Reference Guide (Cloud), pp. 1980-1983

```baan
Syntax: long btext.nfe0001.modify.service.invoice.xml(
domain  btorno           i.invoice.fiscal.reference,
domain  btncmp           i.invoice.financial.company,
domain  btncmp           i.invoice.logistic.company,
long             i.invoice.original.xml,
ref             long             o.invoice.custom.xml )
Usage:        Expl:   Use this method to modify the original XML of a service
electronic invoice (NFSe) with custom elements to be sent to the
Brazilian Tax Authority (SEFAZ).
This function is used to modify only electronic service
invoice (NFSe) XML and won't change any data in the electronic
commercial invoice (NFe) XML.
The original XML 'i.invoice.original.xml' will be generated by
LN with the data required by SEFAZ which is applicable to LN.
To modify it, the first thing to do, is to copy the original
invoice XML from the variable 'i.invoice.original.xml', to the
custom invoice XML variable 'o.invoice.custom.xml' using the
function 'xmlDuplicate':
o.invoice.custom.xml = xmlDuplicate(
i.invoice.original.xml)
After the XML is copied, then it is possible modify its nodes
in the custom XML (o.invoice.custom.xml).
The fiscal reference which generated this XML and also the
financial and logistic companies are provided, making it
possible to be independent of only the data available in
the XML, i.e., it is possible to query data in other LN
tables. Be careful when quering data, use the correct logistic
or financial companies.
If a custom XML is generated then it will be sent to the
SEFAZ. If there are no modifications, i.e., the variable
o.invoice.custom.xml = 0, then the original invoice will be sent
to the SEFAZ. If the XMLs are identical, i.e., the contents of
the variable 'i.invoice.original.xml' are the same of the
variable 'o.invoice.custom.xml' then custom XML will be
discarded and the original XML will be sent to the SEFAZ.
Do not copy a XML if no modifications are needed as it will be
logged in the invoice logs as a custom XML. If the XML
is copied and for some reason, should not be modified, use
the function 'xmlDelete' to delete it:
ret.val = xmlDelete(
o.invoice.custom.xml)
o.invoice.custom.xml = 0
To use the error return DALHOOKERROR and/or the function
'dal.set.error.message' declare the library 'bic_dam'
in the 'Declarations' section of the extension modeler:
#include <bic_dam>
!!!!!! DO NOT use .* to select table fields. This will probably
generate errors.
*************************** WARNING ***************************
Be careful when modifying the XML as it can be rejected by
SEFAZ. Infor is not responsible for custom XMLs which are sent
to SEFAZ.
*************************** WARNING ***************************
----------------------------------------------------------------
Start of Example of Implementation
domain  btcom.bpid      invoice.to.bp
domain  btlino          dummy.line
domain  btsli.corn      customer.order
long            compras.node
long            ret.val
tt.init.vars(
o.invoice.custom.xml,
invoice.to.bp,
dummy.line,
customer.order,
compras.node,
ret.val)
|* Get the Invoice                      -to Business Partner field from the
|* invoice header. Do not use the index to do the query.
select  btsli200.itbp:invoice.to.bp
from    btsli200
where   btsli200.fire = :i.invoice.fiscal.reference
and     btsli200._compnr = :i.invoice.financial.company
as set with 1 rows
selectdo
endselect
|* If the business partner is not the one which should get
|* a customized invoice XML, therefore return with no error.
if trim$(invoice.to.bp) <> "BP0000001" then
return(0)
endif
|* Get the customer order of the first line of the invoice.
|* Do not use the index to do the query.
select  btsli201.line:dummy.line,
btsli201.corn:customer.order
from    btsli201
where   btsli201.fire = :i.invoice.fiscal.reference
and     btsli201._compnr = :i.invoice.financial.company
order by btsli201.line
as set with 1 rows
selectdo
endselect
|* If the customer order is empty then no customization is
|* needed, therefore return with no error.
if isspace(customer.order) then
return(0)
endif
|* Copy the original XML to the custom XML variable.
o.invoice.custom.xml = xmlDuplicate(
i.invoice.original.xml)
|* Set the new custom nodes in the custom XML variable.
compras.node = xmlNewNode(
"compra",
XML_ELEMENT,
o.invoice.custom.xml)
ret.val = xmlNewDataElement(
"xPed",
trim$(customer.order),
compras.node)
|* If an error occurs when trying to create a new node,
|* delete the XML, set an error message and return DALHOOKERROR.
if ret.val = 0 then
|* Check if the XML really exist before deleting it.
|* Deleting a non existing XML will trigger a fatal
|* error.
if xmlIsNode(o.invoice.custom.xml) then
ret.val = xmlDelete(
o.invoice.custom.xml)
endif
dal.set.error.message(
"@" &
"Error when trying to create " &
"the custom XML node 'xPed'.")
o.invoice.custom.xml = 0
return(DALHOOKERROR)
endif
return(0)
End of Example of Implementation
----------------------------------------------------------------
Pre:    n.a.
Post:   n.a.
Input:  i.invoice.fiscal.reference                    - Invoice fiscal reference
i.invoice.financial.company                           - Invoice financial company
i.invoice.logistic.company                            - Invoice logistic company
i.invoice.original.xml                                - Original NFSe XML
Output: o.invoice.custom.xml                          - Custom NFSe XML
```
