# curl.escape.encode$()

## Syntax:
`function string curl.escape.encode$( const string SomeText )`

## Description
Escape a string

## Arguments
| | | |
|---|---|---|
| `const string` | `SomeText` |  Pass a string with special characters, which need to be escaped.  |

## Return values
Contains an escaped string

## Context
This function is implemented in the porting set and can be used in all script types.
