# Get left sibling of a Node

## Syntax:
`function long xmlGetLeftSibling( long node )`

## Description
Get the left sibling node of a node.

## Arguments
| | | |
|---|---|---|
| `long` | `node` |  *node* is the node for which the sibling node is obtained.  |

## Return values
| | |
|---|---|
| <> 0 | Success; Reference to the found sibling *node* when successful. |
| 0 | Error. |

## Context
This function is implemented in the porting set and can be used in all script types.
