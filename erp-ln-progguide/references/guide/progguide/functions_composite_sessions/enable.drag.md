# enable.drag()

## Syntax:
`function void enable.drag( )`

## Description
Enable dragging objects from this 4GL-session to other sessions. This function must be called from the *before.program:* section or from the *after.form.read:* section of a multi-occurrence 4GL-Session which runs as a composite child.

## Context
This function is implemented in the 4GL Engine and can be used in 4GL script types.
