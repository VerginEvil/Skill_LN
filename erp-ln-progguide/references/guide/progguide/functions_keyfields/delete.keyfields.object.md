# delete.keyfields.object()

## Syntax:
`function void delete.keyfields.object( long object )`

## Description
Delete the indicated key fields object. When this object is currently part of a collection it will also be removed from this collection.

## Arguments
| | | |
|---|---|---|
| `long` | `object` |  ID of the key fields object which must be returned by a previous call to [create.keyfields.object()](create.keyfields.object.md)  |

## Context
This function is implemented in the 4GL Engine and can be used in all script types.
