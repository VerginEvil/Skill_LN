# delete.keyfields.collection()

## Syntax:
`function void delete.keyfields.collection( long object )`

## Description
Delete the indicated key fields collection including all key field objects which are currently stored in this collection

## Arguments
| | | |
|---|---|---|
| `long` | `object` |  ID of the key fields collection which must be returned by a previous call to [create.keyfields.collection()](create.keyfields.collection.md)  |

## Context
This function is implemented in the 4GL Engine and can be used in all script types.
