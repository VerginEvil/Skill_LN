# get.next.keyfields.object()

## Syntax:
`function long get.next.keyfields.object( long object )`

## Description
Get the next key fields object in a collection.

## Arguments
| | | |
|---|---|---|
| `long` | `object` |  ID of a key fields object which is part of a collection  |

## Return values
| | |
|---|---|
| <> 0 | The id of the next key fields object |
| 0 | When this collection does not contain more objects |

## Context
This function is implemented in the 4GL Engine and can be used in all script types.
