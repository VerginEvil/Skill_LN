# is.rbhp.mode()

## Syntax:
`function boolean is.rbhp.mode( )`

## Description
This function can be used to check whether this 4GL session is directly started from a Role Based Home Page.

## Return values
true session started from a Role Based Home Page
false sessioin not started from a Role Based Home Page

## Context
This function is implemented in the 4GL Engine and can be used in 4GL script types.
