# tan()

## Syntax:
`function double tan( double x )`

## Description
This computes the tangent of *x*, in radians. The *x* argument can be a long or a double.

## Arguments
| | | |
|---|---|---|
| `double` | `x` |  |

## Return values
The tangent of *x*.

## Context
This function is implemented in the porting set and can be used in all script types.
