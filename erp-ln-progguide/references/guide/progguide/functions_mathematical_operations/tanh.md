# tanh()

## Syntax:
`function double tanh( double x )`

## Description
This computes the hyperbolic tangent of *x*.

## Arguments
| | | |
|---|---|---|
| `double` | `x` |    |

## Return values
The hyperbolic tangent of *x*.

## Context
This function is implemented in the porting set and can be used in all script types.
