# exp()

## Syntax:
`function double exp( double x )`

## Description
This returns the exponent of *x*. That is, it computes the value of the mathematical constant e (2.7182818) raised to the power of *x*.

## Arguments
| | | |
|---|---|---|
| `double` | `x` |    |

## Return values
The exponent of x.

## Context
This function is implemented in the porting set and can be used in all script types.
