# acos()

## Syntax:
`function double acos( double x )`

## Description
This computes the arc cosine of *x.* The value of *x* must be in the range [-1, 1].

## Arguments
| | | |
|---|---|---|
| `double` | `x` |    |

## Return values
The arc cosine of *x*, expressed as a floating point number in the range [0, p] radians.

## Context
This function is implemented in the porting set and can be used in all script types.
