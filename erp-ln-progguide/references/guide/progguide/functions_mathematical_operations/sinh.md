# sinh()

## Syntax:
`function double sinh( double x )`

## Description
This computes the hyperbolic sine of *x*.

## Arguments
| | | |
|---|---|---|
| `double` | `x` |  |

## Return values
The hyperbolic sine of *x*.

## Context
This function is implemented in the porting set and can be used in all script types.
