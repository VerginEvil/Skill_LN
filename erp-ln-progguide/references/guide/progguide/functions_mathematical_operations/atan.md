# atan()

## Syntax:
`function double atan( double x )`

## Description
This computes the arc tangent of *x.*

## Arguments
| | | |
|---|---|---|
| `double` | `x` |    |

## Return values
The arc tangent of *x*, expressed as a floating point number in the range [-p/2, p/2] radians.

## Context
This function is implemented in the porting set and can be used in all script types.
