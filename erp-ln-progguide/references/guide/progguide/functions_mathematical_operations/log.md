# log()

## Syntax:
`function double log( double x )`

## Description
This computes the natural logarithm of *x*. The value of *x* must be greater than zero.

## Arguments
| | | |
|---|---|---|
| `double` | `x` |  |

## Return values
The log of *x*.

## Context
This function is implemented in the porting set and can be used in all script types.
