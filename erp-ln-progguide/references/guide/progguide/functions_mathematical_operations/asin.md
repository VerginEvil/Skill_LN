# asin()

## Syntax:
`function double asin( double x )`

## Description
This computes the arc sine of *x.* The value of *x* must be in the range [-1, 1].

## Arguments
| | | |
|---|---|---|
| `double` | `x` |    |

## Return values
The arc sine of *x*, expressed as a floating point number in the range [-p/2, p/2] radians.

## Context
This function is implemented in the porting set and can be used in all script types.
