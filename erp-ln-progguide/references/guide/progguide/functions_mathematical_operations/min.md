# min()

## Syntax:
`function double min( double x, double x )`

## Description
This compares the values of the two arguments and returns whichever is the smallest. The arguments can be of type long or double or can contain any numeric expression.

## Arguments
| | | |
|---|---|---|
| `double` | `x` |  |
| `double` | `x` |  |

## Return values
The lesser of the two values.

## Context
This function is implemented in the porting set and can be used in all script types.
