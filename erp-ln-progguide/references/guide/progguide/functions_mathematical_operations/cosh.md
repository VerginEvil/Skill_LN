# cosh()

## Syntax:
`function double cosh( double x )`

## Description
This computes the hyperbolic cosine of *x*.

## Arguments
| | | |
|---|---|---|
| `double` | `x` |  |

## Return values
The hyperbolic cosine of *x*.

## Context
This function is implemented in the porting set and can be used in all script types.
