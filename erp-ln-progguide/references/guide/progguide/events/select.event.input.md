# select.event.input()

## Syntax:
`function void select.event.input( long object_id, long masks )`

## Description
This defines which event types can be generated by the specified object.

## Arguments
| | | |
|---|---|---|
| `long` | `object_id` |  The ID of the object to which the specified masks apply.  |
| `long` | `masks` |  A combination of one or more values that indicate the event types that the specified object can generate. If the event queue already contains events not specified by this function, they are NOT removed from the queue. The possible event mask values are:  |

## Context
This function is implemented in the porting set and can be used in all script types.
Notes  Events of type EVTCLIENTMESSAGE, EVTBUCKETMESSAGE, and EVTTIMEREVENT are always selected.
You cannot add to the currently selected events by calling *select.event.input()* with the additional masks. You must specify all required event masks each time you call the function.

## Example
```

long object_id
select.event.input(object_id, EVTBUTTONPRESSMASK + EVTKEYPRESSMASK)
```
