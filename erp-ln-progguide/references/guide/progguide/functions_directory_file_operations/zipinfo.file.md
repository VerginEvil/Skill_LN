# zipinfo.file()

## Syntax:
`function string zipinfo.file( long handle )`

## Description
Retrieves attribute file.

## Arguments
| | | |
|---|---|---|
| `long` | `handle` |  a handle to a zipinfo object. Retrieved by zipinfo.new() or zipfile.info().  |

## Return values
the name of a zipfile for which a zipinfo object is or will be created

## Context
This function is implemented in the 4GL Engine and can be used in all script types.
Note  This function is available from [TIV](../tiv/tiv_overview.md) [1900](../tiv/tiv_1900.md).
