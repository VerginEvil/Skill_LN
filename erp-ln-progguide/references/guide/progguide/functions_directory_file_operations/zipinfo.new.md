# zipinfo.new()

## Syntax:
`function long zipinfo.new( const string zipfile )`

## Description
Returns a new empty zipinfo object for the specified zipfile.

## Arguments
| | | |
|---|---|---|
| `const string` | `zipfile` |  the name of a zipfile for which a zipinfo object must be created.  |

## Return values
| | |
|---|---|
| <> 0 | a handle to the new zipinfo object |
| 0 | in case of failure. |

## Context
This function is implemented in the 4GL Engine and can be used in all script types.
Note  This function is available from [TIV](../tiv/tiv_overview.md) [1900](../tiv/tiv_1900.md).
