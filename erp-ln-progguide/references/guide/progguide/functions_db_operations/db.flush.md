# db.flush()

## Syntax:
`function long db.flush( )`

## Description
All buffered actions are flushed to the database.

## Return values
| | |
|---|---|
| 0 | Success. |
| <> 0 | Error. |

## Context
This function is implemented in the porting set and can be used in all script types.
