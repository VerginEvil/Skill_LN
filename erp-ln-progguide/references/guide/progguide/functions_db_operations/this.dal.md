# this.dal()

## Syntax:
`#include <bic_dal>`
`function string this.dal( )`

## Description
Returns the name of the current DAL.
Note: This function can only be called from the current DAL!

## Return values
the name of the current DAL

## Context
This function is implemented in the 4GL Engine and can be used in DAL script types.
