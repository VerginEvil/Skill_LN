# restore.rcd.main()

## Syntax:
`function void restore.rcd.main( long occurrence )`

## Description
This updates the main table with the contents of the buffer of the specified occurrence. It also makes the specified occurrence the current occurrence.

## Arguments
| | | |
|---|---|---|
| `long` | `occurrence` |  The occurrence number.  |

## Context
This function is implemented in the 4GL Engine and can be used in 4GL script types.
