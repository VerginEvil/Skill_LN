# get.utc.byte.count()

## Syntax:
`function long get.utc.byte.count( )`

## Description
This function returns the value [ByteCountOfUtc](../functions_date_time_zones/overview.md#ByteCountOfUtc), that is the number of bytes used when a [UTC](../functions_date_time_zones/overview.md#utc) long format value is stored in or retrieved from a sequence of bytes.

## Context
This function is implemented in the porting set and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2000.
