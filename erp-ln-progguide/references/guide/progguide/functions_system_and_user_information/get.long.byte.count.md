# get.long.byte.count()

## Syntax:
`function long get.long.byte.count( )`

## Description
This function returns the value [BitCountOfLong](../3gl_features/data_types.md#BitCountOfLong)/8, that is the size (counted in bytes) of a [variable of type long](../3gl_features/data_types.md#long).

## Context
This function is implemented in the porting set and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2000.
