# Json.newNumber()

## Syntax:
`#include <bic_json>`
`function long Json.newNumber( long|double value )`

## Description
Creates a new JSON number value, containing the passed 3GL long or double value.

## Arguments
| | | |
|---|---|---|
| `long|double` | `value` |  A long or a double.  |

## Return values
A new JSON number value, containing the passed 3GL long or double value.

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2120.
