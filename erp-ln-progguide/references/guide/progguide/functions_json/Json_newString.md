# Json.newString()

## Syntax:
`#include <bic_json>`
`function long Json.newString( const string value )`

## Description
Creates a new JSON string value, containing the passed string value.

## Arguments
| | | |
|---|---|---|
| `const string` | `value` |  A string.  |

## Return values
A new JSON string value, containing the passed string value.

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2120.
