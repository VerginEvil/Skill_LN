# Json.isJson

## Syntax:
`#include <bic_json>`
`function boolean Json.isJson( long json_value )`

## Description
Tests whether parameter 'json_value' is a JSON value.

## Arguments
| | | |
|---|---|---|
| `long` | `json_value` |  A JSON value.  |

## Return values
*true* if parameter 'json_value' is a JSON value, else *false*.

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2120.
