# Json.newDouble()

## Syntax:
`#include <bic_json>`
`function long Json.newDouble( double value )`

## Description
Creates a new JSON number value, containing the passed 3GL double value.
This function is an alias for: `Json.newNumber(value)`

## Arguments
| | | |
|---|---|---|
| `double` | `value` |  A double value.  |

## Return values
A new JSON number value, containing the passed 3GL double value.

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2370.
