# Json.boolean()

## Syntax:
`#include <bic_json>`
`function boolean Json.boolean( long json_value )`

## Description
Returns the 3GL value of a JSON boolean value.

## Arguments
| | | |
|---|---|---|
| `long` | `json_value` |  A JSON boolean value.  |

## Return values
true or false

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2120.

## Preconditions
- Parameter 'json_value' is a JSON value of type JSON_TYPE_BOOLEAN.
