# Json.newBoolean()

## Syntax:
`#include <bic_json>`
`function long Json.newBoolean( boolean value )`

## Description
Creates a new JSON boolean value, containing the passed 3GL boolean value.

## Arguments
| | | |
|---|---|---|
| `boolean` | `value` |  A 3GL boolean, either true of false.  |

## Return values
A new JSON boolean value, containing the passed boolean value.

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2120.
