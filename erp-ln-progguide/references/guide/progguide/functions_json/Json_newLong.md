# Json.newLong()

## Syntax:
`#include <bic_json>`
`function long Json.newLong( long value )`

## Description
Creates a new JSON number value, containing the passed 3GL long value.
This function is an alias for: `Json.newNumber(value)`

## Arguments
| | | |
|---|---|---|
| `long` | `value` |  A long value.  |

## Return values
A new JSON number value, containing the passed 3GL long value.

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2370.
