# ASCII Conversion - Overview and Synopsis

## Overview
Use these functions to convert characters to their corresponding [ASCII](../misc/ascii_table.md) or [TSS](../misc/tss.md) code points, and vice versa.

## Synopsis
| | | |
|---|---|---|
| `long` | [asc](asc.md) | `( string characters )` |
| `string` | [chr$](chr.md) | `( long code_point )` |
