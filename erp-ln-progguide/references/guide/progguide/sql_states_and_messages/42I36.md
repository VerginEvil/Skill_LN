# 42I36 - Multiple array size hints specified
An SQL statement contains a HINT clause that contains more than one array size hint.

## Example
```

select *
from   dbtst120
hint   array fetching
and    array size 100
and    array size 50
```
This query causes the error:
SQLState 42I36: Multiple array size hints specified
