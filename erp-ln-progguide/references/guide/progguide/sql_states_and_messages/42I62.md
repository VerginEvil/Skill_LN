# 42I62 - REFERS TO predicate in WHERE clause of UPDATE statement
An SQL UPDATE statement contains a REFERS TO predicate in its WHERE clause.

## Example
```

update dbtst120
set    edlevel = 0
where  workdept refers to dbtst100
```
The WHERE clause of an UPDATE statement may not contain a REFERS TO predicate, unless it is part of the WHERE clause of a subquery of this UPDATE statement. This statement will cause the error:
SQLState 42I62: REFERS TO predicate in WHERE clause of UPDATE statement
