# 42I39 - Invalid buffer size
An SQL statement contains a buffer size hint with a size value less than 1.

## Example
```

select *
from   dbtst120
hint   buffer 0 rows
```
The buffer size that you specify with the buffer size hint must be at least 1. This query causes the error:
SQLState 42I39: Invalid buffer size 0. Size must be greater than or equal to 1
