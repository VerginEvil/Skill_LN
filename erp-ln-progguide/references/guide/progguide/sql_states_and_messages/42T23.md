# 42T23 - Incompatible types for INRANGE
An SQL statement contains an INRANGE predicate and the operands of this INRANGE predicate do not have comparable datatypes.

## Example
```

select empno
from   dbtst120
where  workdept inrange 1 and 10
```
Column workdept is of type string. String and integer are not comparable datatypes. This query will cause the error:
SQLState 42T23: Incompatible types for INRANGE operator
