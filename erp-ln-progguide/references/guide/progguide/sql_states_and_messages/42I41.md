# 42I41 - Multiple ordered hints specified
An SQL statement contains a HINT clause that contains more than one ordered hint.

## Example
```

select *
from   dbtst120, dbtst100
where  dbtst120.workdept = dbtst100.deptno
hint   ordered
and    ordered
```
This query causes the error:
SQLState 42I41: Multiple ordered hints specified
