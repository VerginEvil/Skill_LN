# 42I16 - REFERS TO predicate in NOT condition
An SQL statement contains a REFERS TO predicate that is contained in a NOT condition.

## Example
```

select *
from   dbtst120, dbtst100
where  empno > 100 and not ( empno < 100 and workdept refers to dbtst100 )
```
This query causes the error:
SQLState 42I16: REFERS TO predicate in NOT condition
