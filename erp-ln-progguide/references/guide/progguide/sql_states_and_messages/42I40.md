# 42I40 - Multiple string hints specified
An SQL statement contains a HINT clause that contains more than one string hint.

## Example
```

select *
from   dbtst120
hint   "USE_NL"
and    "FIRST_ROWS"
```
This query causes the error:
SQLState 42I40: Multiple string hints specified
Multiple hints can be combined in one string hint:
```

select *
from   dbtst120
hint   "USE_NL FIRST_ROWS"
```
