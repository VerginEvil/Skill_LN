# 42I85 - Invalid CASE expression
At least one of the result expressions of a CASE expression must specify a value expression.

## Example
```

select
	case
	when empno = 10 then NULL
	end
from dbtst120
```
```

select
	case empno
	when 10 then NULL
	end
from dbtst120
```
These queries will both cause the error:
SQLState 42I85: At least one of the result expressions of a CASE expression must specify a value expression
