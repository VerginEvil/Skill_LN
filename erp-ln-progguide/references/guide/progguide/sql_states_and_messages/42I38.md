# 42I38 - Multiple buffer size hints specified
An SQL statement contains a HINT clause that contains more than one buffer size hint.

## Example
```

select *
from   dbtst120
hint   buffer 100 rows
and    buffer 20 rows
```
This query causes the error:
SQLState 42I38: Multiple buffer size hints specified
