# 42I71 - Queries in UNION have different number of result columns
An SQL statement contains a UNION operator that combines two queries that select a different number of columns.

## Example 1
```

select empno, deptname
from   dbtst120, dbtst100
union  all
select mgrno
from   dbtst100
```
The first query of this UNION selects two columns, whereas the second query selects just one column. This query will cause the error:
SQLState 42I71: Queries in UNION have different number of result columns

## Example 2
```

select empno
from   dbtst120
union  all
select _index1
from   dbtst180
```
The first query of the UNION selects one column. The second query selects four columns, because the combined column _index1 contains four child columns. This query will cause the error:
SQLState 42I71: Queries in UNION have different number of result columns
