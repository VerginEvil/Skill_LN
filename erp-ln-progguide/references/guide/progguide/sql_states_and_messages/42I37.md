# 42I37 - Invalid array size
An SQL statement contains an array size hint with a size value less than 1.

## Example
```

select *
from   dbtst120
hint   array size 0
```
The array size that you specify with the array size hint must be at least 1. This query causes the error:
SQLState 42I37: Invalid array size 0. Size must be greater than or equal to 1
