# 42I34 - Multiple row mode hints specified
An SQL statement contains a HINT clause that contains more than one row mode hint.

## Example
```

select *
from   dbtst120
hint   all rows
and    first rows
```
This query causes the error:
SQLState 42I34: Multiple row mode hints specified
