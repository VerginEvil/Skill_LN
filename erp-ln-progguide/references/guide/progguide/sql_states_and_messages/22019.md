# 22019 - Invalid escape character
An SQL statement contains an ansi LIKE predicate with an invalid ESCAPE character

## Example
```

select * from dbtst120 where firstnme alike 'c%' escape 'xx'
```
The length of the escape value must be equal to 1.
SqlState=22019, '', NativeError=319
It can be solved by assuring that the escape value has a length of 1.
```

select * from dbtst120 where firstnme alike 'c%' escape 'x'
```
