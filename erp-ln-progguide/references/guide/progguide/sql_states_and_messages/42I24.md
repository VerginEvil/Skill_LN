# 42I24 - DATE.TO.NUM does not represent a valid date
An SQL statement contains the date function DATE.TO.NUM and that function could not calculate a valid date.

## Example
```

select firstnme
from   dbtst120
where  hiredate > date.to.num(2000, 12, 32)
```
This query causes the error:
SQLState 42I24: DATE.TO.NUM(2000,12,32) does not represent a valid date
