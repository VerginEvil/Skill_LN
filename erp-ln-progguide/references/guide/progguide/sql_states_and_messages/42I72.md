# 42I72 - A query in a UNION cannot be a FOR UPDATE query
A query contains a UNION operator and one of the queries of this UNION contains a table that is marked FOR UPDATE.

## Example
```

select empno
from   dbtst120 for update
where  _compnr = 0
union  all
select empno
from   dbtst120 for update
where  _compnr = 1
```
A query that is part of a UNION cannot contain tables that are marked FOR UPDATE. Table dbtst120 is marked FOR UPDATE in both queries of the UNION. This will cause the error:
SQLState 42I72: A query in a UNION cannot be a FOR UPDATE query
