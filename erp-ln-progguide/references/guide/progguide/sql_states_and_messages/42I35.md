# 42I35 - Multiple array fetching hints specified
An SQL statement contains a HINT clause that contains more than one array fetching hint.

## Example
```

select *
from   dbtst120
hint   array fetching
and    no array fetching
```
This query causes the error:
SQLState 42I35: Multiple array fetching hints specified
