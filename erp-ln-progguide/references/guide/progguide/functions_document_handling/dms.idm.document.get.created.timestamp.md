# dms.idm.document.get.created.timestamp

## Syntax:
`#include <bic_dms>`
`function string dms.idm.document.get.created.timestamp( )`

## Description
Get the creation time of a document in a query response.

## Return values
The creation time of the document in ISO 8601 format "yyyy-mm-ddThh:mm:ss + hh:mm".

## Context
This function is implemented in the 4GL Tools and can be used in all script types.
