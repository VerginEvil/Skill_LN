# dms.idm.document.get.mimetype

## Syntax:
`#include <bic_dms>`
`function string dms.idm.document.get.mimetype( )`

## Description
Get the mimetype of a document in a query response.

## Return values
The mimetype of the document

## Context
This function is implemented in the 4GL Tools and can be used in all script types.
