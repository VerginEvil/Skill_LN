# dms.dochub.document.get.filename

## Syntax:
`#include <bic_dms>`
`function string dms.dochub.document.get.filename( )`

## Description
Get the filename of a document in a query response.

## Return values
The filename of the document

## Context
This function is implemented in the 4GL Tools and can be used in all script types.
