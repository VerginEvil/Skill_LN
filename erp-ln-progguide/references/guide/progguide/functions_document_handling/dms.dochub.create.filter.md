# dms.dochub.create.filter

## Syntax:
`#include <bic_dms>`
`function long dms.dochub.create.filter( )`

## Description
Create an empty filter which can be used for a query request.

## Return values
An empty filter which can be used as input for a query request.

## Context
This function is implemented in the 4GL Tools and can be used in all script types.
