# dms.idm.document.get.last.changed.by

## Syntax:
`#include <bic_dms>`
`function string dms.idm.document.get.last.changed.by( )`

## Description
Get the last changed by user of a document in a query response.

## Return values
The last changed by user of the document.

## Context
This function is implemented in the 4GL Tools and can be used in all script types.
