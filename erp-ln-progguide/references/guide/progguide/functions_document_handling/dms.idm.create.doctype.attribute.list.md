# dms.idm.create.doctype.attribute.list

## Syntax:
`#include <bic_dms>`
`function long dms.idm.create.doctype.attribute.list( )`

## Description
Create an empty document type attribute list which can be used for a query or upload request.

## Return values
An empty attribute list which can be used as input for a query or upload request.

## Context
This function is implemented in the 4GL Tools and can be used in all script types.
