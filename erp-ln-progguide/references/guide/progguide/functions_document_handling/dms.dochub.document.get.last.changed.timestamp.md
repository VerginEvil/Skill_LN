# dms.dochub.document.get.last.changed.timestamp

## Syntax:
`#include <bic_dms>`
`function string dms.dochub.document.get.last.changed.timestamp( )`

## Description
Get the last changed time of a document in a query response.

## Return values
The last changed time of the document in ISO 8601 format "yyyy-mm-ddThh:mm:ss + hh:mm".

## Context
This function is implemented in the 4GL Tools and can be used in all script types.
