# is.image.dropped()

## Syntax:
`function boolean is.image.dropped( string fieldname )`

## Description
This function can be used to check whether an image has been dropped onto the image field or the image is deleted which is not yet saved or discarded.

## Arguments
| | | |
|---|---|---|
| `string` | `fieldname` |  The name of the image field on the form.  |

## Return values
| | |
|---|---|
| true | When an image is changed for this image field. |
| false | When no image is changed for this image field. |

## Context
This function is implemented in the 4GL Engine and can be used in 4GL script types.
