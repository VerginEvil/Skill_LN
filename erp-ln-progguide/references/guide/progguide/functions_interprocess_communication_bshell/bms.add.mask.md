# bms.add.mask()

## Syntax:
`function void bms.add.mask( string mask, [ long processno ] )`

## Description
This adds the specified mask to a process. If you specify a process number, the mask is added to that process. Otherwise, the mask is added to the current process.

## Arguments
| | | |
|---|---|---|
| `string` | `mask` |  |
| `[ long` | `processno ]` |  |

## Context
This function is implemented in the porting set and can be used in all script types.
