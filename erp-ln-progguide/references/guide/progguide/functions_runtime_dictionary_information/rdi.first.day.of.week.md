# rdi.first.day.of.week()

## Syntax:
`function long rdi.first.day.of.week( )`

## Description
This function returns the first day of the week as defined for the company of the user. The returned number is relative to Sunday (=1). So, for example, if the function returns 2, this indicates that Monday is the user's first day of the week.

## Return values
The user's first day of the week.

## Context
This function is implemented in the porting set and can be used in all script types.
