# domainof()

## Syntax:
`function string domainof( string variable )`

## Description
This compile time function returns the name of the domain of the supplied variable.

## Arguments
| | | |
|---|---|---|
| `string` | `variable` |  The type of this variable must be a domain type, otherwise a compile time error will occur.  |

## Return values
The name of the domain of the supplied variable.

## Context
This function is implemented in the porting set and can be used in all script types.
