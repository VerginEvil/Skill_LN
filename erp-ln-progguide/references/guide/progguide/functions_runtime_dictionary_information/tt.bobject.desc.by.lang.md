# tt.bobject.desc.by.lang()

## Syntax:
`function string tt.bobject.desc.by.lang( string b_object(10), string language(1) )`

## Description
This retrieves the description of a specified business object ( *b_object*) in the specific language.

## Arguments
| | | |
|---|---|---|
| `string` | `b_object(10)` |  The business object.  |
| `string` | `language(1)` |  The language of the description  |

## Return values
The description is returned.

## Context
This function is implemented in the 4GL Engine and can be used in all script types.

## Remarks
This function is available from TIV level 2380.
