# tt.demrole()

## Syntax:
`function string tt.demrole( )`

## Description
This returns the current DEM Role of the current user.

## Return values
The current DEM role, or empty string if the current role is not set.

## Context
This function is implemented in the 4GL Tools and can be used in all script types.
