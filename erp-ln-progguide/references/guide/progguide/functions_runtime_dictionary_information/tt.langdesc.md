# tt.langdesc()

## Syntax:
`function boolean tt.langdesc( string language, ref string desc() mb )`

## Description

## Arguments
| | | |
|---|---|---|
| `string` | `language` |    |
| `ref string` | `desc() mb` |    |

## Return values
false error; language not found
true success

## Context
This function is implemented in the 4GL Tools and can be used in all script types.

## Description
This retrieves the description of the specified language and stores it in the *desc* argument.
