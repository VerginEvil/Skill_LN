# Substitute session overview
Infor Enterprise Server provides several mechanisms for starting one session from another – these are zoom fields, synchronized sessions, and the 4GL [start.session()](../functions_starting_and_stopping_programs/start.session.md) function. This section discusses substitute sessions and associated functions.
When two or more sessions should be substituted for one another and at one point in time, only one session should be visible, this mechanism should be used.
