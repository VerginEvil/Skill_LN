# Transfer of control
The Baan 3GL programming language supports several statements that change the flow of control in a program. These enable control to be transferred either conditionally or unconditionally to a specified point in the program.
Use the [GOTO statement](the_goto_statement.md) to transfer control unconditionally to a specified point.
Use the [IF statement](the_if_then_else_statement.md) or the [ON CASE statement](the_on_case_statement.md) for conditional transfer. These latter statements evaluate a specified condition and transfer control if the condition is TRUE.
