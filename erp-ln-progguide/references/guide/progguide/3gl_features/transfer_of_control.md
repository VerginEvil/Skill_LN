# Transfer of control
The Baan 3GL programming language supports several statements that change the flow of control in a program. These enable control to be transferred either conditionally or unconditionally to a specified point in the program.
You use the [GOTO](the_goto_statement.md) statement to transfer control unconditionally to a specified point. You use the [IF...THEN...ELSE](the_if_then_else_statement.md) statement or the [ON CASE](the_on_case_statement.md) statement for conditional transfer. These latter statements evaluate a specified condition and transfer control if the condition is TRUE.
