# Preprocessor
The bic6.2 compiler for 3GL program scripts has a built in preprocessor with the following functions:
- [Include files (preprocessor)](include_files_preprocessor.md)
- [Macro definition (preprocessor)](macro_definition_preprocessor.md)
- [Token pasting (preprocessor)](token_pasting_preprocessor.md)
- [Object identifications (preprocessor)](object_identifications_preprocessor.md)
- [Pragma codes (preprocessor)](pragma_codes_preprocessor.md)
- [Conditional compilation (preprocessor)](conditional_compilation_preprocessor.md)  All preprocessor directives starts with a '#'. A preprocessor directive must be the first word on a source line, possibly with leading spaces or tabs.
