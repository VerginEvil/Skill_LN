# Multi Language Values
Infor Enterprise Server provides support to store multibyte strings - like descriptions - in multiple languages.
A Multi Language Value denotes the contents of a multibyte string variable. When Multi Language is enabled for the Infor Enterprise Server environment, conceptually all multibyte string variables (whether defined as MLF or not), will be treated as MLVs. This means that some of these variables conceptually will hold different translations (in case the contents is from a real Multi Language Field in the database) and some will hold the same translation for all defined Data Languages (in case the contents is from a single language field in the database).
