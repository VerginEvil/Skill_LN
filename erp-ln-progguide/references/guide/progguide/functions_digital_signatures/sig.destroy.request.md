# sig.destroy.request

## Syntax:
`#include <bic_sig>`
`function void sig.destroy.request( long i.request )`

## Description
Clean up all resources related to the request.

## Arguments
| | | |
|---|---|---|
| `long` | `i.request` |  The handle to the request as returned by a previous call to, for example, [sig.init.sign.request](sig.init.sign.request.md)  |

## Context
This function is implemented in the 4GL Tools and can be used in all script types.
