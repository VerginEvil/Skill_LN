# time.num()

## Syntax:
`function long time.num( )`

## Description
This returns the current time as the number of seconds since 00:00.
The applicable timezone can be found with the function [get.time.zone()](get.time.zone.md).

## Context
This function is implemented in the porting set and can be used in all script types.

## Return value
The current time as the number of seconds since 00:00.
