# utc.num()

## Syntax:
`function long utc.num( )`

## Description
This returns the current local date and time in UTC long format.

## Return values
| | |
|---|---|
|  | The UTC long format value. |
| -1 | Error. |

## Context
This function is implemented in the porting set and can be used in all script types.
