# DsCgraph

## Description
A graph is a rectangular child window that displays a graph. The DsCgraph object is not part of the standard Infor Enterprise Server object library. It is a third-party OCX control. It can be controlled from 3GL scripts in the same way as standard objects. Several graphs can be displayed simultaneously within the same main window. A wide range of graph types is supported.

## Events
A DsCgraph object can generate the following events:
EVTBUTTONPRESS
EVTBUTTONRELEASE
The parameters of these events are as described in [Event array parameters](../events/event_array_parameters.md), with the following exceptions:
evt.button.x The graph set selected.
evt.button.y The graph point selected.
evt.button.rootx The x-coordinate (Graphic Server units).
evt.button.rooty The y-coordinate (Graphic Server units).
evt.button.state 0 when a graph set/point is selected
(Shift and Control states are not supported).
