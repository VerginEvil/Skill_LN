# set.enum.values()

## Syntax:
`function void set.enum.values( enum_constant enum_constant,... )`

## Description
This restricts the values valid for the ask.enum() function. Only the values specified are shown as buttons.

## Arguments
| | | |
|---|---|---|
| `enum_constant` | `enum_constant,...` |  The name of the constant.  |

## Context
This function is implemented in the porting set and can be used in all script types.
Notes  This function is *deprecated*. Use *set.ask.enum.values* instead.
