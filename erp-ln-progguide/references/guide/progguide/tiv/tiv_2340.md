# TIV 2340

## Porting set 9.3e
-  New bshell functionality added:
- Optional ref long argument *declared.length* added to bshell function [array.info()](../functions_memory_operations/array.info.md).
- Bshell function [concat$()](../functions_string_operations/concat.md) now can use a multibyte TSS character as the separator character.
- The string returned by bshell function [concat$()](../functions_string_operations/concat.md) now will be of type multibyte string when the supplied separator string or any of the supplied values is of that type.
- Bshell function [mb.char()](../functions_multibyte_strings/mb.char.md) assesses values in the range [0x9c000000 … 0xffffffff] as ‘not the code point of any [TSS](../misc/tss.md) character’ (return value 0). In earlier versions of the bshell, values in this range are assessed as the code point of a multibyte [TSS](../misc/tss.md) character (return value 2).
- Bshell function [mb.type()](../functions_multibyte_strings/mb.type.md) accepts arguments of any type, not only arguments of type string.
- Bshell function [in.fips.mode()](../functions_govcloud/in.fips.mode.md) returns 1 in case the Porting Set runs in GovCloud FIPS-140-2 mode
