# TIV 1700
With TIV 1700 the following functionality has been added:

## Porting set 8.7a
- Added support for namespaces in XML api.
- [alloc.mem()](../functions_memory_operations/alloc.mem.md) supports resizing of any dimension.
- Functions [pos()](../functions_string_operations/pos.md) and [rpos()](../functions_string_operations/rpos.md) support an optional offset argument.
