# TIV 2030

## Porting set 9.0b.01
-  Porting set functionality added: Warnings triggered by [bic compiler option -W32](../3gl_features/compiler.md) are not suppressed by [#pragma nowarnings](../3gl_features/pragma_codes_preprocessor.md).
- Messages triggered by [bshell resource debug_long64](../misc/bshell_resources.md) are saved in a separate log file in a separate directory.
- [Bshell resource debug_long64](../misc/bshell_resources.md) flags ArithmeticOverflow and Long64Usage are also active when the bshell does not use its debug cpu.

- [path.exists()](../functions_directory_file_operations/path.exists.md)
