# Editable grid and Synchronized Dialog
This addresses sessions with both an editable grid and a synchronized dialog only.
| | |
|---|---|
| TIV | Behavior |
| < 1000 | By default the synchronized dialog is used to insert a record. |
| >= 1000 | By default the grid is used to insert a record. |
In both cases the default can be overridden by specifying the 3rd argument of the [set.synchronized.dialog()](../functions_synchronized_sessions/set.synchronized.dialog.md) function.
