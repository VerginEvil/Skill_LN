# progress.indicator.exists()

## Syntax:
`function boolean progress.indicator.exists( )`

## Description
This checks if a progress indicator was already created.
Only one progress indicator can be active at the same time.

## Return values
| | |
|---|---|
| True | Progress Indicator Exists |
| False | No Progress Indicator Exists |

## Context
This function is implemented in the 4GL Engine and can be used in all script types.
