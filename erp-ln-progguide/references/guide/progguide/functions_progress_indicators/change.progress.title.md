# change.progress.title()

## Syntax:
`function void change.progress.title( string title )`

## Description
Changes the title of the progress indicator.

## Arguments
| | | |
|---|---|---|
| `string` | `title` |  The new title.  |

## Context
This function is implemented in the 4GL Engine and can be used in all script types.
