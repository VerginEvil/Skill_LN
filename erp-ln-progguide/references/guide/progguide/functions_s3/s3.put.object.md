# s3.put.object()

## Syntax:
`function long s3.put.object( const string s3.path$, const string bytes$, long num.bytes, [ long compress.method ] )`

## Description
Writes the specified bytes to an S3 object. If the S3 object exists, it is overwritten. If `num.bytes` < 0, all bytes in `bytes$` are written.
Notes
- The S3 folder in which the S3 object is to be written, must exist, or else `-ENOENT` is returned.
- This function is not meant to be used for creating very large S3 objects, as that would require to first create a very large buffer in memory, which can lead to out-of-memory errors. In order to create very large S3 objects, it is advised to first open the S3 object for writing using [s3.open.object](s3.open.object.md) and then write blocks of data using [seq.write](../functions_directory_file_operations/seq.write.md), and then close the stream.     If required, the content of the S3 object can be compressed by specifying one of the following compression methods:
- `SEQ_COMPRESSION_METHOD_GZIP`
- `SEQ_COMPRESSION_METHOD_DEFLATE`  Example:
```

long    num.bytes.written

num.bytes.written = s3.put.object("${AWS_S3}/documents/expenses.csv", "Coffee,2.75,2024-05-27", -1)

if num.bytes.written < 0 then
        |* an error occurred, handle error here...
endif

|* now with GZIP compression...
num.bytes.written = s3.put.object(
                "${AWS_S3}/documents/expenses.csv",
                "Coffee,2.75,2024-05-27",
                -1,
                SEQ_COMPRESSION_METHOD_GZIP)

if num.bytes.written < 0 then
        |* an error occurred, handle error here...
endif
```

## Arguments
-
-
| | | |
|---|---|---|
| `const string` | `s3.path$` |  an S3 path; this is a single byte string of max `S3_PATH_SIZE (1088)` bytes  |
| `const string` | `bytes$` |  the buffer containing the bytes that must be written  |
| `long` | `num.bytes` |  the number of bytes to read from `bytes$` and write to the S3 object; if this is a negative number, then all bytes are written  |
| `[ long` | `compress.method ]` |  optional, one of: `SEQ_COMPRESSION_METHOD_GZIP`: use GZIP compression `SEQ_COMPRESSION_METHOD_DEFLATE`: use Deflate compression if not specified, the data is not compressed while writing the S3 object  |

## Return values
| | |
|---|---|
| `>= 0` | The number of bytes written to S3 |
| `< 0` | This is the negative system error code, like `-EACCES`, `-EINVAL`, etc.  |
Notes
- In case of an error, the predefined variable `e` is set as well.
- You can call ` [s3.error.argument$](s3.error.argument$.md)` to get the name of the argument that caused the error.

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2510.
This function is marked as 'conditionally trusted' and can therefore only be used in trusted objects or 'conditionally' in not trusted objects. More about trusted and not trusted objects can be found in the section about [managed execution.](../misc/managed_execution.md).
