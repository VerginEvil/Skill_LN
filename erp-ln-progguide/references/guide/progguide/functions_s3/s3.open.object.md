# s3.open.object()

## Syntax:
`function long s3.open.object( const string s3.path$, string mode$(1), [ long bufsz ] )`

## Description
Opens an S3 object and returns a stream handle. For mode `"r"` you can specify a buffer size between 16 kB and 5 MB. When not specified, a default buffer size of 16 kB is used. For mode `"w"` the buffer size is fixed to 5 MB.
Notes
- If an S3 object is opened for writing, the S3 folder in which the S3 object must be created, must exist, or else `-ENOENT` is returned.
- If an S3 object is opened for writing, the S3 object is not yet physically created in S3 until the stream is closed. Any data written to the stream is first buffered, and when the stream is closed, the actual S3 object is written.     Example:
```

long    stream
long    ret
string  line(128)

|* open for reading, with a buffer size of 64 kB
stream = s3.open.object("${AWS_S3}/documents/expenses.csv", "r", 64 * 1024)
if stream > 0 then
        |* read line from stream ...
        ret = seq.gets(line, 128, stream)
        |* close stream
        ret = seq.close(stream)
endif

|* open for writing; note that the S3 object does not yet exist after this call!
stream = s3.open.object("${AWS_S3_TMP}/errors.log", "w")
if stream > 0 then
        |* write error to file; this data is buffered
        ret = seq.puts("Error 3 while processing invoice ABC12345", stream)
        |* close stream; now the S3 object comes into existence; therefore
        |* it is important to check the return value
        ret = seq.close(stream)

        if ret <> 0 then
                |* handle error
        endif
endif
```

## Arguments
-
-
| | | |
|---|---|---|
| `const string` | `s3.path$` |  an S3 path; this is a single byte string of max `S3_PATH_SIZE (1088)` bytes  |
| `string` | `mode$(1)` |  one of: `"r"`: open the S3 object for reading `"w"`: open the S3 object for writing  |
| `[ long` | `bufsz ]` |  optional, only applies to `mode$ = "r"`, the buffer size to use expressed in bytes; the minimum buffer size is 16 kB (16384 bytes), the maximum buffer size is 5 MB (5242880 bytes); if not specified, a default buffer size of 16 kB is used  |

## Return values
| | |
|---|---|
| `> 0` | A stream handle |
| `< 0` | This is the negative system error code, like `-ENOENT`, `-EINVAL`, etc.  |
Notes
- In case of an error, the predefined variable `e` is set as well.
- You can call ` [s3.error.argument$](s3.error.argument$.md)` to get the name of the argument that caused the error.
