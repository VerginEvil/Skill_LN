# s3.uri.to.path$()

## Syntax:
`function string s3.uri.to.path$( const string s3.uri$ )`

## Description
Returns the S3 path equivalent of an S3 URI. If the S3 URI does not start with `s3://`, it is assumed the S3 URI is actually already an S3 path, and is returned as is.
Example:
```

string  s3.uri$(S3_URI_SIZE)
string  s3.path$(S3_PATH_SIZE)

s3.uri$ = "s3://${AWS_S3}/documents/expenses.xlsx"
s3.path$ = s3.uri.to.path$(s3.uri$)
|* s3.path$ now contains "${AWS_S3}/documents/expenses.xlsx"

|* when passing an S3 path instead of an S3 URI, the S3 path is returned as-is
s3.uri$ = "${AWS_S3}/documents/expenses.xlsx"
s3.path$ = s3.uri.to.path$(s3.uri$)
|* s3.path$ now contains "${AWS_S3}/documents/expenses.xlsx"
```

## Arguments
| | | |
|---|---|---|
| `const string` | `s3.uri$` |  an S3 URI; this is a single byte string of max `S3_URI_SIZE (1093)` bytes  |

## Return values
an S3 path; this is a single byte string of max `S3_PATH_SIZE (1088)` bytes

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2510.
