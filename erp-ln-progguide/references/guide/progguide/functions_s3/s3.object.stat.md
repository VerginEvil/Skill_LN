# s3.object.stat()

## Syntax:
`function long s3.object.stat( const string s3.path$, ref long size, [ ref long modification.date ] )`

## Description
Returns status information about the S3 object identified by the specified S3 path. I.e. the size in bytes and optionally the last modification date.
Example:
```

long    result
long    size
long    modification.date

result = s3.object.stat("${AWS_S3}/documents/expenses.xlsx", size, modification.date)
```

## Arguments
| | | |
|---|---|---|
| `const string` | `s3.path$` |  an S3 path; this is a single byte string of max `S3_PATH_SIZE (1088)` bytes  |
| `ref long` | `size` |  the retrieved size in bytes of the S3 object  |
| `[ ref long` | `modification.date ]` |  optional, the retrieved modification date (a UTC date) of the S3 object  |

## Return values
| | |
|---|---|
| `0` | Status information about the S3 object was retrieved |
| `<> 0` | The specified S3 object could not be accessed; the actual return value is a system error code like `ENOENT`, `EACCES`, `EIO` etc. |

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2530.
