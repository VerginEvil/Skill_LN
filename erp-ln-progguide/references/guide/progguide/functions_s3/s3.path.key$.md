# s3.path.key$()

## Syntax:
`function string s3.path.key$( const string s3.path$ )`

## Description
Returns the key of an S3 path. When the path starts with a symbolic location, like `${AWS_S3}` or `AWS_S3_admin/tmp/` then the key is the part after the symbolic location. If the path is an expanded path, then the key is the part after the bucket. Note that the returned key never begins with a forward slash.
Example:
```

string  s3.path$(S3_PATH_SIZE)
string  s3.key$(S3_KEY_SIZE)

|* example with S3 path using a symbolic location
s3.path$ = "${AWS_S3}/documents/expenses.xlsx"
s3.key$ = s3.path.key$(s3.path$)
|* s3.key$ now contains "documents/expenses.xlsx"

|* example with S3 path using a File Manager symbolic location
s3.path$ = "AWS_S3_admin/tmp/documents/expenses.xlsx"
s3.key$ = s3.path.key$(s3.path$)
|* s3.key$ now contains "documents/expenses.xlsx"

|* example with expanded S3 path
s3.path$ = "infor-dde-dev-appdata-us-east-1/eln/data/usea1dden/tenants/APPLN001_TST/appdata/documents/expenses.xlsx"
s3.key$ = s3.path.key$(s3.path$)
|* s3.key$ now contains "eln/data/usea1dden/tenants/APPLN001_TST/appdata/documents/expenses.xlsx"
```

## Arguments
| | | |
|---|---|---|
| `const string` | `s3.path$` |  an S3 path; this is a single byte string of max `S3_PATH_SIZE (1088)` bytes  |

## Return values
an S3 key; this is a single byte string of max `S3_KEY_SIZE (1024)` bytes

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2510.
This function is marked as 'conditionally trusted' and can therefore only be used in trusted objects or 'conditionally' in not trusted objects. More about trusted and not trusted objects can be found in the section about [managed execution.](../misc/managed_execution.md).
