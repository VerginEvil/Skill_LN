# s3.copy.object()

## Syntax:
`function long s3.copy.object( const string source.s3.path$, const string target.s3.path$ )`

## Description
Copies an S3 object from one location in S3 to another location in S3. If the source or the target is a folder, an error is returned. If the target exists, it is overwritten.
Note  The S3 folder in which the target is to be written, must exist, or else `-ENOENT` is returned.
Example:
```

long    error

|* copy to another file in the same folder
error = s3.copy.object("${AWS_S3}/documents/expenses.csv", "${AWS_S3}/documents/expenses.bak")
if error <> 0 then
        |* an error occurred, handle error here...
endif

|* copy to another folder
error = s3.copy.object("${AWS_S3}/documents/expenses.csv", "${AWS_S3}/backup/expenses.csv")
if error <> 0 then
        |* an error occurred, handle error here...
endif

|* copy to another bucket
error = s3.copy.object("${AWS_S3}/documents/expenses.csv", "${AWS_S3_TMP}/documents/expenses.csv")
if error <> 0 then
        |* an error occurred, handle error here...
endif
```

## Arguments
| | | |
|---|---|---|
| `const string` | `source.s3.path$` |  the source S3 path; this is a single byte string of max `S3_PATH_SIZE (1088)` bytes  |
| `const string` | `target.s3.path$` |  the target S3 path; this is a single byte string of max `S3_PATH_SIZE (1088)` bytes  |

## Return values
| | |
|---|---|
| `0` | The S3 object has been copied |
| `<> 0` | This is the system error code, like `EINVAL`, `EISDIR`, etc. |

- In case of an error, the predefined variable `e` is set as well.

- You can call [s3.error.argument$](s3.error.argument$.md) to get the name of the argument that caused the error.
