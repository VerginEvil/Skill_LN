# s3.location.to.path$()

## Syntax:
`function string s3.location.to.path$( long s3.location, const string s3.key$, [ long symbolize.mode ] )`

## Description
Returns the S3 path of the given location and key, in the format `<location>/<key>`, where `<location>` is the symbolic name for the given location.
If `symbolize.mode` is not specified, or if it equals `S3_SYMBOLIZE_MODE_DEFAULT`, the returned path will start with `${AWS_S3}` or `${AWS_S3_TMP}` respectively. If `symbolize.mode` equals `S3_SYMBOLIZE_MODE_FILEMAN`, the returned path will start with `AWS_S3` or `AWS_S3_admin/tmp` respectively.
Returns an empty string in case an invalid location is specified.
Example:
```

long    s3.location
string  s3.key$(S3_KEY_SIZE)
string  s3.path$(S3_PATH_SIZE)

s3.location = S3.location.appdata
s3.key$ = "documents/expenses.xlsx"
s3.path$ = s3.location.to.path$(S3.location, s3.key$)
|* s3.path$ now contains "${AWS_S3}/documents/expenses.xlsx"

s3.location = S3.location.tmp
s3.key$ = "images/car.jpg"
s3.path$ = s3.location.to.path$(S3.location, s3.key$)
|* s3.path$ now contains "${AWS_S3_TMP}/images/car.jpg"

|* ensure a File Manager symbolic name is used
s3.location = S3.location.tmp
s3.key$ = "images/car.jpg"
s3.path$ = s3.location.to.path$(S3.location, s3.key$, S3_SYMBOLIZE_MODE_FILEMAN)
|* s3.path$ now contains "AWS_S3_admin/tmp/images/car.jpg"
```

## Arguments
-
-
| | | |
|---|---|---|
| `long` | `s3.location` |  an S3 location, one of: `S3.location.appdata`, `S3.location.tmp`  |
| `const string` | `s3.key$` |  an S3 key; this is a single byte string of max `S3_KEY_SIZE (1024)` bytes  |
| `[ long` | `symbolize.mode ]` |  optional, determines which symbolic names will be applied; one of: `S3_SYMBOLIZE_MODE_DEFAULT`: this uses `${AWS_S3}` or `${AWS_S3_TMP}` `S3_SYMBOLIZE_MODE_FILEMAN`: this uses `AWS_S3` or `AWS_S3_admin/tmp` if not specified, `S3_SYMBOLIZE_MODE_DEFAULT` is used.  |

## Return values
an S3 path, which is a single byte string of max `S3_PATH_SIZE (1088)` bytes, or an empty string if an invalid location was specified
