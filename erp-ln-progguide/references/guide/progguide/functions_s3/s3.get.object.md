# s3.get.object()

## Syntax:
`function long s3.get.object( const string s3.path$, ref string bytes$, long num.bytes, [ long compress.method ] )`

## Description
Reads the specified number of bytes from an S3 object. If `num.bytes` < 0, bytes are read until `bytes$` is completely full, or if `bytes$` is resizable, `bytes$` is resized such that all bytes from the object are retrieved.
Notes
- Take care with very large files; you may get out-of-memory errors.
- When `bytes$` is resized, it can be larger than the actual number of bytes read from the S3 object. Always use the return value to see how many bytes actually have been read and stored in `bytes$`.     If the S3 object contents is compressed, you can decompress the contents by specifying the compression method:
- `SEQ_COMPRESSION_METHOD_GZIP`
- `SEQ_COMPRESSION_METHOD_DEFLATE`  Example:
```

long    num.bytes.read
string	bytes$(1) based

|* read the first 100 bytes
alloc.mem(bytes$, 100)
num.bytes.read = s3.get.object("${AWS_S3}/documents/expenses.csv", bytes$, 100)
|* if successful, num.bytes.read is between 0 and 100 bytes, depending on the actual
|* size of the S3 object
free.mem(bytes$)

|* now read all bytes and let bytes$ be resized
num.bytes.read = s3.get.object("${AWS_S3}/documents/expenses.csv", bytes$, -1)

if num.bytes.read < 0 then
        |* an error occurred, handle error here...
else
        |* as 'bytes$' is BASED, it has now been resized such that it contains
        |* all bytes read from the S3 object

        |* do something with the read bytes, using the exact number of bytes
        |* that have been read:
        if str_pos(bytes$(1;num.bytes.read), ",") > 0 then
                |* ...
        endif
endif

|* if the file was compressed using GZIP, apply decompression;
|* bytes$ will contain the decompressed data
num.bytes.read = s3.get.object("${AWS_S3}/documents/expenses.csv.gz", bytes$, -1, SEQ_COMPRESSION_METHOD_GZIP)

if num.bytes.read < 0 then
        |* an error occurred, handle error here...
endif
```

## Arguments
-
-
| | | |
|---|---|---|
| `const string` | `s3.path$` |  an S3 path; this is a single byte string of max `S3_PATH_SIZE (1088)` bytes  |
| `ref string` | `bytes$` |  the buffer that upon return, contains the bytes that have been read  |
| `long` | `num.bytes` |  the number of bytes to read from the S3 object and that must be stored in `bytes$`; if this is a negative number, then if `bytes$` is resizable, all bytes from the S3 object are retrieved and written to `bytes$` and if `bytes$` is not resizable, then reading from the S3 object is done either until `bytes$` is full, or until all bytes have been read from the S3 object, whichever condition occurs first. Note that this is always the uncompressed number of bytes.  |
| `[ long` | `compress.method ]` |  optional, one of: `SEQ_COMPRESSION_METHOD_GZIP`: use if the S3 object was compressed using GZIP compression `SEQ_COMPRESSION_METHOD_DEFLATE`: use if the S3 object was compressed using Deflate compression if not specified, the data is not decompressed while retrieving the S3 object  |

## Return values
| | |
|---|---|
| `>= 0` | The number of bytes read from S3 |
| `< 0` | This is the negative system error code, like `-ENOENT`, `-EINVAL`, etc.  |
Notes
- In case of an error, the predefined variable `e` is set as well.
- You can call ` [s3.error.argument$](s3.error.argument$.md)` to get the name of the argument that caused the error.

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2510.
This function is marked as 'conditionally trusted' and can therefore only be used in trusted objects or 'conditionally' in not trusted objects. More about trusted and not trusted objects can be found in the section about [managed execution.](../misc/managed_execution.md).
