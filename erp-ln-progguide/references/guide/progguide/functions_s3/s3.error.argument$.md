# s3.error.argument$()

## Syntax:
`function string s3.error.argument$( )`

## Description
Returns the name of the argument that has a value that is causing the last error. Examples:

- if `e = EINVAL`, the returned argument has an invalid value.

- if `e = ENOENT`, the returned argument specifies a path that does not exist.

- if `e = EISDIR`, the returned argument specifies a path that is a directory.

- if `e = EEXIST`, the returned argument specifies a path that should not exist.

Example:
```

long    stream
string  arg.name$(32)

|* 'mode$' value is invalid when opening an S3 object;
|* mode is either "r" or "w"", and cannot be combined
stream = s3.open.object("${AWS_S3}/documents/expenses.xlsx", "rw")
if stream < 0 then
        arg.name$ = s3.error.argument$()
        |* arg.name$ now contains "mode$"
        on case e
        case EINVAL:
               message("Argument '%s' of function s3.open.object() has an invalid value", arg.name$)
        case ...:
        endcase
endif
```

## Return values
The name of the argument that caused the last error

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2510.
