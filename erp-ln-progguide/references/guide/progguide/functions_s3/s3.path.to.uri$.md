# s3.path.to.uri$()

## Syntax:
`function string s3.path.to.uri$( const string s3.path$ )`

## Description
Returns the S3 URI equivalent of the specified S3 path. An S3 URI has the format: `s3://<path>`.

- The specified S3 path is not validated to see if it represents a valid S3 path.

- This function does not expand symbolic names; if the given S3 path contains e.g. `${AWS_S3}`, then the returned S3 URI will also contain this symbolic name. Use [s3.path.expand$](s3.path.expand$.md) to expand any symbolic names.

Example:
```

string  s3.path$(S3_PATH_SIZE)
string  s3.uri$(S3_URI_SIZE)

s3.path$ = "${AWS_S3}/documents/expenses.xlsx"
s3.uri$ = s3.path.to.uri$(s3.path$)
|* s3.uri$ now contains "s3://${AWS_S3}/documents/expenses.xlsx"
```

## Arguments
| | | |
|---|---|---|
| `const string` | `s3.path$` |  an S3 path; this is a single byte string of max `S3_PATH_SIZE (1088)` bytes  |

## Return values
an S3 URI; this is a single byte string of max `S3_URI_SIZE (1093)` bytes

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2510.
