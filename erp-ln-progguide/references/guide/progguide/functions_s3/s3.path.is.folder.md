# s3.path.is.folder()

## Syntax:
`function boolean s3.path.is.folder( const string s3.path$ )`

## Description
Returns true if the specified S3 path denotes a folder, i.e. the path ends with a forward slash. If the specified S3 path is equal to one of the symbolic names: `${AWS_S3}`, `${AWS_S3_TMP}`, `AWS_S3`, `AWS_S3_admin/tmp`, then the path is seen as a folder as well.
Example:
```

string  s3.path$(S3_PATH_SIZE)
boolean is.folder

s3.path$ = "${AWS_S3}/documents/"
is.folder = s3.path.is.folder(s3.path$)
|* is.folder now equals true

s3.path$ = "${AWS_S3}"
is.folder = s3.path.is.folder(s3.path$)
|* is.folder now equals true

s3.path$ = "${AWS_S3}/documents/expenses.xlsx"
is.folder = s3.path.is.folder(s3.path$)
|* is.folder now equals false
```

## Arguments
| | | |
|---|---|---|
| `const string` | `s3.path$` |  an S3 path; this is a single byte string of max `S3_PATH_SIZE (1088)` bytes  |

## Return values
*true* if the S3 path denotes a folder, *false* otherwise

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2510.
