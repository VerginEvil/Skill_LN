# s3.create.folder()

## Syntax:
`function long s3.create.folder( const string s3.path$ )`

## Description
Creates a folder in S3. This is an empty S3 object with a key ending with a forward slash. This function creates a folder hierarchy if required.
It is not required to specify a key ending with a forward slash, but the key of the S3 object that is created will end with a forward slash. If parts in a folder structure already exist, they are not overwritten, in order to keep the object date intact.
Example:
```

long    error

|* create a folder structure; this creates all folders in the hierarchy
error = s3.create.folder("${AWS_S3}/documents/2024/05")
|* if error = 0, this has created 3 folders if they did not yet exist:
|* ${AWS_S3}/documents/
|* ${AWS_S3}/documents/2024
|* ${AWS_S3}/documents/2024/05/
```

## Arguments
| | | |
|---|---|---|
| `const string` | `s3.path$` |  an S3 path denoting a folder; this is a single byte string of max `S3_PATH_SIZE (1088)` bytes  |

## Return values
| | |
|---|---|
| `0` | Success |
| `<> 0` | This is the system error code, like `EACCES`, `EINVAL`, etc.  |
Notes
- In case of an error, the predefined variable `e` is set as well.
- You can call ` [s3.error.argument$](s3.error.argument$.md)` to get the name of the argument that caused the error.

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2510.
This function is marked as 'conditionally trusted' and can therefore only be used in trusted objects or 'conditionally' in not trusted objects. More about trusted and not trusted objects can be found in the section about [managed execution.](../misc/managed_execution.md).
