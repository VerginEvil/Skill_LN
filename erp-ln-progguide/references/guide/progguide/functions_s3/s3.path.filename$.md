# s3.path.filename$()

## Syntax:
`function string s3.path.filename$( const string s3.path$ )`

## Description
Returns the file name of an S3 path, e.g., the file name of `"${AWS_S3}/design.docx"` is `"design.docx"`.
Example:
```

string  s3.path$(S3_PATH_SIZE)
string  s3.filename$(32)

s3.path$ = "${AWS_S3}/documents/expenses.xlsx"
s3.filename$ = s3.path.filename$(s3.path$)
|* s3.filename$ now contains "expenses.xlsx"

s3.path$ = "${AWS_S3}/documents/expenses-bak"
s3.filename$ = s3.path.filename$(s3.path$)
|* s3.filename$ now contains "expenses-bak"

s3.path$ = "${AWS_S3}/old.docs/"
s3.filename$ = s3.path.filename$(s3.path$)
|* s3.filename$ now contains "" as the S3 path denotes a folder instead of a file
```

## Arguments
| | | |
|---|---|---|
| `const string` | `s3.path$` |  an S3 path; this is a single byte string of max `S3_PATH_SIZE (1088)` bytes  |

## Return values
a file name, or an empty string if the path does not point to a file

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2510.
