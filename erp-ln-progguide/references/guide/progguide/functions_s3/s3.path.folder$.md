# s3.path.folder$()

## Syntax:
`function string s3.path.folder$( const string s3.path$ )`

## Description
Returns the folder of the specified S3 path. Examples: `"a/b"` becomes `"a/"`, `"a/b/"` becomes `"a/"`, and `"a/"` becomes an empty string.
Example:
```

string  s3.path$(S3_PATH_SIZE)

|* get the folder of a path referring to a file
s3.path$ = "${AWS_S3}/documents/expenses.xlsx"
s3.path$ = s3.path.folder$(s3.path$)
|* s3.path$ now contains "${AWS_S3}/documents/"

|* get the folder of a path referring to a folder
s3.path$ = "${AWS_S3}/documents/"
s3.path$ = s3.path.folder$(s3.path$)
|* s3.path$ now contains "${AWS_S3}/"
```

## Arguments
| | | |
|---|---|---|
| `const string` | `s3.path$` |  an S3 path; this is a single byte string of max `S3_PATH_SIZE (1088)` bytes  |

## Return values
the part of the S3 path that denotes the folder of the S3 path

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2510.
