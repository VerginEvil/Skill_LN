# s3.path.extension$()

## Syntax:
`function string s3.path.extension$( const string s3.path$ )`

## Description
Returns the file extension of an S3 path, e.g., the extension of `"${AWS_S3}/design.docx"` is `".docx"`.
Example:
```

string  s3.path$(S3_PATH_SIZE)
string  s3.extension$(10)

s3.path$ = "${AWS_S3}/documents/expenses.xlsx"
s3.extension$ = s3.path.extension$(s3.path$)
|* s3.extension$ now contains ".xlsx"

s3.path$ = "${AWS_S3}/documents/expenses-bak"
s3.extension$ = s3.path.extension$(s3.path$)
|* s3.extension$ now contains ""

s3.path$ = "${AWS_S3}/old.docs/"
s3.extension$ = s3.path.extension$(s3.path$)
|* s3.extension$ now contains "" as the S3 path denotes a folder instead of a file
```

## Arguments
| | | |
|---|---|---|
| `const string` | `s3.path$` |  an S3 path; this is a single byte string of max `S3_PATH_SIZE (1088)` bytes  |

## Return values
a file extension, including the leading dot, like `".docx"`

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2510.
