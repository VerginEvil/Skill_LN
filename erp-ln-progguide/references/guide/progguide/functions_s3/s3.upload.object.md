# s3.upload.object()

## Syntax:
`function long s3.upload.object( const string s3.path$, const string file.path$, [ long compress.method ] )`

## Description
Uploads a file from the regular file system to S3. This function automatically creates any S3 folder in the specified S3 path as required.
If required, the content of the S3 object can be compressed by specifying one of the following compression methods:
- `SEQ_COMPRESSION_METHOD_GZIP`
- `SEQ_COMPRESSION_METHOD_DEFLATE`  Example:
```

long    error

|* upload a temp file to S3
error = s3.upload.object("${AWS_S3}/documents/expenses.csv", "${BSE_TMP}/tmp123949476")
if error <> 0 then
        |* an error occurred, handle error here...
endif
```

## Arguments
-
-
| | | |
|---|---|---|
| `const string` | `s3.path$` |  an S3 path; this is a single byte string of max `S3_PATH_SIZE (1088)` bytes  |
| `const string` | `file.path$` |  the path of the file to upload; this cannot be a directory  |
| `[ long` | `compress.method ]` |  optional, one of: `SEQ_COMPRESSION_METHOD_GZIP`: use GZIP compression `SEQ_COMPRESSION_METHOD_DEFLATE`: use Deflate compression if not specified, the data is not compressed while uploading  |

## Return values
| | |
|---|---|
| `0` | The upload was successful |
| `<> 0` | This is the system error code, like `EINVAL`, `EACCES`, etc.  |
Notes
- In case of an error, the predefined variable `e` is set as well.
- You can call ` [s3.error.argument$](s3.error.argument$.md)` to get the name of the argument that caused the error.

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2510.
This function is marked as 'conditionally trusted' and can therefore only be used in trusted objects or 'conditionally' in not trusted objects. More about trusted and not trusted objects can be found in the section about [managed execution.](../misc/managed_execution.md).
