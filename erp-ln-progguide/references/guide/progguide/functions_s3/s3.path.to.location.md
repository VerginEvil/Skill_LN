# s3.path.to.location()

## Syntax:
`function long s3.path.to.location( const string s3.path$, ref string s3.key$ )`

## Description
Splits the specified S3 path into a location and a key. If successful, the return value is one of the locations `S3.location.appdata` or `S3.location.tmp`, while the key is returned as an output parameter. If the path contains an unsupported location, 0 is returned.
The S3 path may contain one of the following symbolic names:
- `${AWS_S3}`: points to the S3 appdata location
- `${AWS_S3_TMP}`: points to the S3 tmp location
- `AWS_S3`: used in the File Manager; points to the S3 appdata location
- `AWS_S3_admin/tmp`: used in the File Manager; points to the S3 tmp location   Use this function if you have an S3 path but want to directly use portingset functions like [seq.s3.open.file](../functions_directory_file_operations/seq.s3.open.file.md).
Example:
```

string  s3.path$(S3_PATH_SIZE)
long    s3.location
string  s3.key$(S3_KEY_SIZE)
long    s3.fp

|* use the S3 appdata location
s3.path$ = "${AWS_S3}/documents/expenses.xlsx"
s3.location = s3.path.to.location(s3.path$, s3.key$)
|* s3.location now equals S3.location.appdata
|* s3.key$ now equals "documents/expenses.xlsx"

|* now with the File Manager S3 appdata location
s3.path$ = "AWS_S3/documents/expenses.xlsx"
s3.location = s3.path.to.location(s3.path$, s3.key$)
|* s3.location now equals S3.location.appdata
|* s3.key$ now equals "documents/expenses.xlsx"

|* use the S3 tmp location
s3.path$ = "${AWS_S3_TMP}/images/car.jpg"
s3.location = s3.path.to.location(s3.path$, s3.key$)
|* s3.location now equals S3.location.tmp
|* s3.key$ now equals "images/car.jpg"

|* now with the File Manager S3 tmp location
s3.path$ = "AWS_S3_admin/tmp/images/car.jpg"
s3.location = s3.path.to.location(s3.path$, s3.key$)
|* s3.location now equals S3.location.tmp
|* s3.key$ now equals "images/car.jpg"

|* using the location and key with a portingset function:
s3.fp = seq.s3.open.file(s3.path.to.location(s3.path$, s3.key$), s3.key$, "r")
if s3.fp > 0 then
        |* read from file ...
        seq.close(s3.fp)
endif
```

## Arguments
| | | |
|---|---|---|
| `const string` | `s3.path$` |  an S3 path, like `"${AWS_S3}/documents/expenses.xlsx"`; this is a single byte string of max `S3_PATH_SIZE (1088)` bytes  |
| `ref string` | `s3.key$` |  the returned S3 key; this is a single byte string of max `S3_KEY_SIZE (1024)` bytes  |

## Return values
| | |
|---|---|
| `S3.location.appdata` | The specified S3 path points to the appdata location |
| `S3.location.tmp` | The specified S3 path points to the tmp location |
| `0` | The specified S3 path points to an unsupported location |

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2510.
This function is marked as 'conditionally trusted' and can therefore only be used in trusted objects or 'conditionally' in not trusted objects. More about trusted and not trusted objects can be found in the section about [managed execution.](../misc/managed_execution.md).
