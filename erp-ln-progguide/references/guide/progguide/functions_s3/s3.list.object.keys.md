# s3.list.object.keys()

## Syntax:
`function long s3.list.object.keys( const string s3.path$, long type, ref long object.keys )`

## Description
Retrieves a list of keys of S3 objects (files, folders, both or a tree) in the form of a JSON string array. The keys are relative to the specified S3 folder. Note that the JSON array can be empty.
Note  Do not forget to delete the returned JSON array with [Json.delete](../functions_json/Json_delete.md) when no longer needed
Example:
```

|* Suppose S3 folder ${AWS_S3}/documents has the following files and folders:
|* 2024-01/
|*   presentation.pptx
|* 2024-02/
|*   suppliers.xlsx
|* design.docx
|* expenses.csv

long    error
long    object.keys
long    i
string  s3.folder$(S3_PATH_SIZE)
string  s3.key$(S3_KEY_SIZE)

s3.folder$ = "${AWS_S3}/documents/"

|* list all files in S3 folder ${AWS_S3}/documents/
error = s3.list.object.keys(s3.folder$, S3_LIST_FILES, object.keys)
|* object.keys now contains:
|* [
|*   "design.docx",
|*   "expenses.csv"
|* ]

|* list all folders in S3 folder ${AWS_S3}/documents
error = s3.list.object.keys(s3.folder$, S3_LIST_FOLDERS, object.keys)
|* object.keys now contains:
|* [
|*   "2024-01/",
|*   "2024-02/"
|* ]

|* list all files and folders in S3 folder ${AWS_S3}/documents
error = s3.list.object.keys(s3.folder$, S3_LIST_FILE + S3_LIST_FOLDERS, object.keys)
|* object.keys now contains:
|* [
|*   "2024-01/",
|*   "2024-02/",
|*   "design.docx",
|*   "expenses.csv"
|* ]

|* list the complete tree of all files and folders in S3 folder ${AWS_S3}/documents
error = s3.list.object.keys(s3.folder$, S3_LIST_TREE, object.keys)
|* object.keys now contains:
|* [
|*   "2024-01/",
|*   "2024-01/presentation.pptx",
|*   "2024-02/",
|*   "2024-02/suppliers.xlsx",
|*   "design.docx",
|*   "expenses.csv"
|* ]

|* traverse the contents of the JSON array:
for i = 1 to Json.count(object.keys)
        s3.key$ = Json.stringAt(object.keys, i)
        if s3.path.extension$(s3.key$) = ".docx" then
                error = s3.object.delete(s3.folder$ & s3.key$)
        endif
endfor
```

## Arguments
-
-
-
-
| | | |
|---|---|---|
| `const string` | `s3.path$` |  an S3 path denoting an S3 folder; this is a single byte string of max `S3_PATH_SIZE (1088)` bytes  |
| `long` | `type` |  the following values or combination of values are supported: `S3_LIST_FILES`: list file names in the specified S3 folder `S3_LIST_FOLDERS`: list folder names in the specified S3 folder `S3_LIST_FILES + S3_LIST_FOLDERS`: list both file and folder names in the specified S3 folder `S3_LIST_TREE`: list file and folder names of the complete tree under the specified S3 folder  |
| `ref long` | `object.keys` |  the returned JSON string array containing the keys of the found S3 files and/or folders. The keys are relative to the specified S3 folder  |

## Return values
| | |
|---|---|
| `0` | Success |
| `<> 0` | This is the system error code, like `EINVAL`, `EACCES`, etc.  |
Notes
- In case of an error, the predefined variable `e` is set as well.
- You can call ` [s3.error.argument$](s3.error.argument$.md)` to get the name of the argument that caused the error.

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2510.
This function is marked as 'conditionally trusted' and can therefore only be used in trusted objects or 'conditionally' in not trusted objects. More about trusted and not trusted objects can be found in the section about [managed execution.](../misc/managed_execution.md).
