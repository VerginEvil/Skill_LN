# s3.download.object()

## Syntax:
`function long s3.download.object( const string s3.path$, const string file.path$, [ long compress.method ] )`

## Description
Downloads a file from S3 to the regular file system. The directory to which the S3 object is downloaded is created if it does not yet exist.
If the S3 object contents is compressed, you can decompress the contents by specifying the compression method:
- `SEQ_COMPRESSION_METHOD_GZIP`
- `SEQ_COMPRESSION_METHOD_DEFLATE`  Example:
```

long    error

|* download a file from S3 to $BSE/appdata/docs
error = s3.download.object(
                "${AWS_S3}/documents/expenses.csv",
                path.combine(bse.appdata.dir$(), "docs", "expenses.csv"))

if error <> 0 then
        |* an error occurred, handle error here...
endif
```

## Arguments
-
-
| | | |
|---|---|---|
| `const string` | `s3.path$` |  an S3 path; this is a single byte string of max `S3_PATH_SIZE (1088)` bytes  |
| `const string` | `file.path$` |  the path of the file to which the contents of the S3 object must be downloaded; this cannot be a directory  |
| `[ long` | `compress.method ]` |  optional, one of: `SEQ_COMPRESSION_METHOD_GZIP`: use if the S3 object was compressed using GZIP compression `SEQ_COMPRESSION_METHOD_DEFLATE`: use if the S3 object was compressed using Deflate compression if not specified, the data is not decompressed while downloading  |

## Return values
| | |
|---|---|
| `0` | The download was successful |
| `<> 0` | This is the system error code, like `EINVAL`, `EACCES`, etc.  |
Notes
- In case of an error, the predefined variable `e` is set as well.
- You can call ` [s3.error.argument$](s3.error.argument$.md)` to get the name of the argument that caused the error.

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2510.
This function is marked as 'conditionally trusted' and can therefore only be used in trusted objects or 'conditionally' in not trusted objects. More about trusted and not trusted objects can be found in the section about [managed execution.](../misc/managed_execution.md).
