# s3.path.exists()

## Syntax:
`function boolean s3.path.exists( const string s3.path$ )`

## Description
Returns true if the specified S3 path exists in S3. The path can be a file or a folder.
Example:
```

long    error

if not s3.path.exists("${AWS_S3}/documents/") then
      |* create the S3 folder
      error = s3.create.folder("${AWS_S3}/documents/")
      |* check error...
endif
```

## Arguments
| | | |
|---|---|---|
| `const string` | `s3.path$` |  an S3 path; this is a single byte string of max `S3_PATH_SIZE (1088)` bytes  |

## Return values
*true* if the S3 path exists in S3, *false* otherwise

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2510.
