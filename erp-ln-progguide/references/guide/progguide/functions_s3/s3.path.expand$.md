# s3.path.expand$()

## Syntax:
`function string s3.path.expand$( const string s3.path$ )`

## Description
Expands symbolic names to the actual bucket and prefix represented by the symbolic name. The following symbolic names are understood:

- `${AWS_S3}`: points to the S3 appdata location

- `${AWS_S3_TMP}`: points to the S3 tmp location

- `AWS_S3`: used in the File Manager; points to the S3 appdata location

- `AWS_S3_admin/tmp`: used in the File Manager; points to the S3 tmp location

If these are not found, the specified S3 path is returned as is.
Example:
```

string  s3.path$(S3_PATH_SIZE)

|* suppose this is done for tenant APPLN001_TST in the N-farm in the DDE account
s3.path$ = "${AWS_S3}/documents/expenses.xlsx"
s3.path$ = s3.path.expand$(s3.path$)
|* s3.path$ now contains "infor-dde-dev-appdata-us-east-1/eln/data/usea1dden/tenants/APPLN001_TST/appdata/documents/expenses.xlsx"

s3.path$ = "${AWS_S3}"
s3.path$ = s3.path.expand$(s3.path$)
|* s3.path$ now contains "infor-dde-dev-appdata-us-east-1/eln/data/usea1dden/tenants/APPLN001_TST/appdata/"
```

## Arguments
| | | |
|---|---|---|
| `const string` | `s3.path$` |  an S3 path; this is a single byte string of max `S3_PATH_SIZE (1088)` bytes  |

## Return values
the expanded version of the specified S3 path

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2510.
This function is marked as 'untrusted' and can therefore not be used in custom objects in a cloud-ready environment. See section about [managed execution](../misc/managed_execution.md) for more information.
