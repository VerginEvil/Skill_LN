# s3.path.symbolize$()

## Syntax:
`function string s3.path.symbolize$( const string s3.path$, [ long symbolize.mode ] )`

## Description
Returns the symbolized version of the specified S3 path. If the path begins with a bucket that equals the *S3 appdata prefix* or the *S3 tmp prefix* for the current tenant, this is replaced by a symbolic name.
If `symbolize.mode` is not specified, or if it equals `S3_SYMBOLIZE_MODE_DEFAULT`, the returned path will start with `${AWS_S3}` or `${AWS_S3_TMP}` respectively. If `symbolize.mode` equals `S3_SYMBOLIZE_MODE_FILEMAN`, the returned path will start with `AWS_S3` or `AWS_S3_admin/tmp` respectively.
If the path is already symbolized, e.g. with the File Manager symbolic names, then it is possible to return the path with default symbolic names, and vice versa.
The key behind the prefix is normalized as well. If the S3 path cannot be symbolized, an empty string is returned.
Example:
```

string  s3.path$(S3_PATH_SIZE)

|* suppose this is done for tenant APPLN001_TST in the N-farm in the DDE account
s3.path$ = "infor-dde-dev-appdata-us-east-1/eln/data/usea1dden/tenants/APPLN001_TST/documents/expenses.xlsx"
s3.path$ = s3.path.symbolize$(s3.path$)
|* s3.path$ now contains "${AWS_S3}/documents/expenses.xlsx"

|* now using the File Manager symbolic name
s3.path$ = "infor-dde-dev-appdata-us-east-1/eln/data/usea1dden/tenants/APPLN001_TST/documents/expenses.xlsx"
s3.path$ = s3.path.symbolize$(s3.path$, S3_SYMBOLIZE_MODE_FILEMAN)
|* s3.path$ now contains "AWS_S3/documents/expenses.xlsx"

|* it is also possible to change a File Manager symbolic name to the default symbolic name and vice versa:
s3.path$ = "AWS_S3/documents/expenses.xlsx"
s3.path$ = s3.path.symbolize$(s3.path$, S3_SYMBOLIZE_MODE_DEFAULT)
|* s3.path$ now contains "${AWS_S3}/documents/expenses.xlsx"
s3.path$ = s3.path.symbolize$(s3.path$, S3_SYMBOLIZE_MODE_FILEMAN)
|* s3.path$ now contains "AWS_S3/documents/expenses.xlsx"
```

## Arguments
-
-
| | | |
|---|---|---|
| `const string` | `s3.path$` |  an S3 path; this is a single byte string of max `S3_PATH_SIZE (1088)` bytes  |
| `[ long` | `symbolize.mode ]` |  optional, determines which symbolic names will be applied; one of: `S3_SYMBOLIZE_MODE_DEFAULT`: this uses `${AWS_S3}` or `${AWS_S3_TMP}` `S3_SYMBOLIZE_MODE_FILEMAN`: this uses `AWS_S3` or `AWS_S3_admin/tmp` if not specified, `S3_SYMBOLIZE_MODE_DEFAULT` is used.  |

## Return values
the symbolized version of the specified S3 path

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2510.
This function is marked as 'conditionally trusted' and can therefore only be used in trusted objects or 'conditionally' in not trusted objects. More about trusted and not trusted objects can be found in the section about [managed execution.](../misc/managed_execution.md).
