# s3.copy.folder()

## Syntax:
`function long s3.copy.folder( const string source.s3.path$, const string target.s3.path$, [ const string progress.callback.dll$, const string progress.callback.function$, long progress.callback.data ] )`

## Description
Copies an S3 folder including the complete tree of files and folders below it, to an S3 folder with the specified name. Returns an error if the target folder already exists.
It is possible to pass a progress callback function. This callback function can be used to update an already created progress indicator. The callback function is called right before and after a file is copied. It must have the following prototype:
```

extern long <progress_function>(
   long total.count,            |* total number of files to copy
   long actual.count,           |* number of files that have been copied so far
   const string source.path$,   |* the source file path
   const string target.path$,   |* the target file path
   long data)                   |* any progress callback data, can be XML/JSON
```
This callback function must return 0 to continue, or <> 0 (like `PROGRESS.STOP`) to stop deleting files.
Example:
```

function long copy.s3.folder(const string source.s3.folder$, const string target.s3.folder$)
{
        long    error

        |* copy an S3 folder including everything below it, and show progress

        create.progress.indicator("Copy S3 Folder", PROGRESS.BAR + PROGRESS.STOP + PROGRESS.NOAUTODESTROY)
        error = s3.copy.folder(source.s3.folder$, target.s3.folder$, __OBJECT__, "report.s3.progress")
        destroy.progress.indicator()
        return(error)
}

|* next function is the progress callback function
function extern long report.s3.progress(long total.count, long actual.count,
        const string source.path$, const string target.path$, long data)
{
        return(change.progress.indicator(actual.count * 100 / total.count,
                sprintf$("Copying: %s", s3.path.filename$(source.path$)),
                sprintf$("from: %s", s3.path.folder$(source.path$)),
                sprintf$("to: %s", s3.path.folder$(target.path$))))
}
```

## Arguments
| | | |
|---|---|---|
| `const string` | `source.s3.path$` |  an S3 path denoting the source folder; this is a single byte string of max `S3_PATH_SIZE (1088)` bytes  |
| `const string` | `target.s3.path$` |  an S3 path denoting the target folder; this is a single byte string of max `S3_PATH_SIZE (1088)` bytes  |
| `[ const string` | `progress.callback.dll$ ]` |  the DLL in which the progress callback function is located  |
| `[ const string` | `progress.callback.function$ ]` |  the progress callback function name  |
| `[ long` | `progress.callback.data ]` |  any data you want to pass to the progress callback function; this can be JSON or XML  |

## Return values
| | |
|---|---|
| `0` | Success |
| `<> 0` | In case progress was stopped, `S3_PROGRESS_STOPPED (-99)` is returned; in case of an error this is the system error code, like `EACCES`, `EINVAL`, etc. |

- In case of an error, the predefined variable `e` is set as well.

- You can call [s3.error.argument$](s3.error.argument$.md) to get the name of the argument that caused the error.

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2510.
