# s3.move.object()

## Syntax:
`function long s3.move.object( const string source.s3.path$, const string target.s3.path$ )`

## Description
Moves (or renames) an S3 object from one location in S3 to another location in S3. If the target exists or if the source or the target is a folder, an error is returned.
Notes
- The S3 folder in which the target is to be written, must exist, or else `-ENOENT` is returned.
- S3 itself does not support moving or renaming an S3 object. The move is therefore not an atomic operation: first the source is copied to the target path, and when that is successful, the source is deleted; but if for some reason the source cannot be deleted, the copy is not cleaned up.     Example:
```

long    error

|* move/rename a file in the same folder
error = s3.move.object("${AWS_S3}/documents/draft-expenses.csv", "${AWS_S3}/documents/expenses.csv")
if error <> 0 then
        |* an error occurred, handle error here...
endif

|* move a file to another folder
error = s3.move.object("${AWS_S3}/documents/expenses.csv", "${AWS_S3}/backup/expenses.csv")
if error <> 0 then
        |* an error occurred, handle error here...
endif

|* move to another bucket
error = s3.move.object("${AWS_S3}/documents/expenses.csv", "${AWS_S3_TMP}/documents/expenses.csv")
if error <> 0 then
        |* an error occurred, handle error here...
endif
```

## Arguments
| | | |
|---|---|---|
| `const string` | `source.s3.path$` |  the source S3 path; this is a single byte string of max `S3_PATH_SIZE (1088)` bytes  |
| `const string` | `target.s3.path$` |  the target S3 path; this is a single byte string of max `S3_PATH_SIZE (1088)` bytes  |

## Return values
| | |
|---|---|
| `0` | The S3 object has been moved |
| `<> 0` | This is the system error code, like `EINVAL`, `EISDIR`, etc.  |
Notes
- In case of an error, the predefined variable `e` is set as well.
- You can call ` [s3.error.argument$](s3.error.argument$.md)` to get the name of the argument that caused the error.

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2510.
