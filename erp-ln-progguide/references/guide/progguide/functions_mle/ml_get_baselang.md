# ml_get_baselang()

## Syntax:
`function string ml_get_baselang( )`

## Description
Returns the base language of the environment.

## Return values
the base language of the environment, or "" in case Multi Language support is inactive

## Context
This function is implemented in the 4GL Tools and can be used in all script types.
