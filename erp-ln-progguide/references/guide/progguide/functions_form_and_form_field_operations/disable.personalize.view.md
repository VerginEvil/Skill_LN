# disable.personalize.view()

## Syntax:
`function void disable.personalize.view( )`

## Description
This disables the personalize view option.

## Context
This function is implemented in the 4GL Engine and can be used in all script types.
Note  Use this function for sessions where the view cannot be personalized.
This function should be used in the before program section.
This function is available from TIV 2040.
