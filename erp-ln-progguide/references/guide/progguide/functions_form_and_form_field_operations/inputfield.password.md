# inputfield.password()

## Syntax:
`function void inputfield.password( string field_name(18),... )`

## Description
This causes input to the specified field to be displayed as asterisks (*). To specify a particular element of an array field, append the element number (in parentheses) to the field name. For example: `"ttadv301.labl(2)"`.

## Arguments
| | | |
|---|---|---|
| `string` | `field_name(18),...` |   |

## Context
This function is implemented in the 4GL Engine and can be used in all script types.
