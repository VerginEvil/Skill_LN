# refresh.graph()

## Syntax:
`function void refresh.graph( )`

## Description
This function forces the display of all graph fields based on the most recent data (the current record buffer, the calculations made based on the current record buffer) of the session.
This function can be called by a form command or a field button and is typically called from the session that contains the graph field(s).

## Context
This function is implemented in the 4GL Engine and can be used in 4GL script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2100.
