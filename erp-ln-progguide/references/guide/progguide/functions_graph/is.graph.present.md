# is.graph.present()

## Syntax:
`function boolean is.graph.present( )`

## Description
This function indicates whether there are active graph defined for this session. This function can be used to determine if additional operations/calculations are needed for a graph.

## Return values
| | |
|---|---|
| true | the session is part of an active graph |
| false | otherwise |

## Context
This function is implemented in the 4GL Engine and can be used in 4GL script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2100.
