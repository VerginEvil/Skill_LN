# url.set_port()

## Syntax:
`#include <bic_web>`
`function void url.set_port( long url_instance, long port )`

## Description
Sets the port of a URL instance.

## Arguments
| | | |
|---|---|---|
| `long` | `url_instance` |  A URL instance.  |
| `long` | `port` |  A port number.  |

## Context
This function is implemented in the 4GL Tools and can be used in all script types.

## Availability
This function is available in the following TIV level ranges:
- 2153 - 2199 (ES 10.5.2.1)
- 2231 - 2299 (ES 10.6.1.1)
- 2393 - 2399 (ES 10.7.4.1)
- 2451 and above (ES 10.8.5)
