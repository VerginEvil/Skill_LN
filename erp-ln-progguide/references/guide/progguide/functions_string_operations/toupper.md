# toupper$()

## Syntax:
`function string toupper$( string str )`

## Description
This function converts all lower case characters in its argument to upper case. It returns the converted string expression. The input string remains unchanged.
To convert all upper case characters to lower case, use [tolower$()](tolower.md) instead.

## Arguments
| | | |
|---|---|---|
| `string` | `str` |  |

## Context
This function is implemented in the porting set and can be used in all script types.
Note  This function can handle multibyte characters.
