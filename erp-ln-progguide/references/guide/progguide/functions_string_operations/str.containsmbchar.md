# str.containsMBchar()

## Syntax:
`function boolean str.containsMBchar( const string string$ )`

## Description
Tests whether the specified string contains at least one multibyte character. It does not matter if the string to search in is declared as a single-byte or a multibyte string.

## Arguments
| | | |
|---|---|---|
| `const string` | `string$` |  a string  |

## Return values
| | |
|---|---|
| true | `string$` contains at least one multibyte character |
| false | in any other case |

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 1700.
