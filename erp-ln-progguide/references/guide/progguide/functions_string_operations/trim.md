# trim$()

## Syntax:
`function string trim$( string str )`

## Description
This returns a specified string without the leading and trailing spaces. The input string remains unchanged.

## Arguments
| | | |
|---|---|---|
| `string` | `str` |    |

## Context
This function is implemented in the 4GL Engine and can be used in all script types.

## Example
```

trim$("    ABC   ")      | result  "ABC"
```
