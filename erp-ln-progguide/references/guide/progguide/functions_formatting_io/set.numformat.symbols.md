# set.numformat.symbols()

## Syntax:
`function void set.numformat.symbols( string decimal(1), string grouping(1) )`

## Description
Set the decimal sign and thousand separator. These settings will be used from this moment on for all formatted numbers.

## Arguments
| | | |
|---|---|---|
| `string` | `decimal(1)` |  The character to be used as decimal sign.  |
| `string` | `grouping(1)` |  The character to be used as thousand separator.  |

## Context
This function is implemented in the porting set and can be used in all script types.
