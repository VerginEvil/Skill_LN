# s3.transfer.current.target()

## Syntax:
`function string s3.transfer.current.target( long transfer )`

## Description
Returns the target name of the file that is currently being transferred.
This information is only available for transfers of type: `S3_TRANSFER_TYPE_COPY_DIRECTORY`. This information can be used on a progress indicator.

## Arguments
| | | |
|---|---|---|
| `long` | `transfer` |  an s3.transfer object  |

## Return values
the target name of the file that is being transferred

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2590.
