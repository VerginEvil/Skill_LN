# s3.transfer.result()

## Syntax:
`function long s3.transfer.result( long transfer )`

## Description
Returns the result of an s3 transfer. If a transfer has not yet started, or if it is still in progress, this function returns `0` (No error).

## Arguments
| | | |
|---|---|---|
| `long` | `transfer` |  an s3.transfer object  |

## Return values
| | |
|---|---|
| `0` | No error |
| `-12` | the transfer was started but failed |
| `-13` | the transfer was started but timed out |
| `-21` | the source file or directory does not exist |
| `-22` | the user has no access to the source file or directory |
| `-23` | the path of the source file is a directory |
| `-24` | the path of the source directory does not point to a directory |
| `-31` | the directory of the target file does not exist |
| `-32` | the user has no access to the target file or directory |
| `-33` | the path of the target file is a directory |
| `-34` | the path of the target directory does not point to a directory |
| `-35` | the target directory already exists |
| `-99` | the transfer was started but was aborted by the user |

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2590.
