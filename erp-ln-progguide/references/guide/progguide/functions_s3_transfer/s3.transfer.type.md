# s3.transfer.type()

## Syntax:
`function long s3.transfer.type( long transfer )`

## Description
Returns the type of an S3 transfer.

## Arguments
| | | |
|---|---|---|
| `long` | `transfer` |  an s3.transfer object  |

## Return values
| | |
|---|---|
| `S3_TRANSFER_TYPE_DOWNLOAD` | the transfer is a download of a file |
| `S3_TRANSFER_TYPE_DOWNLOAD_DIRECTORY` | the transfer is a download of a directory |
| `S3_TRANSFER_TYPE_UPLOAD` | the transfer is an upload of a file |
| `S3_TRANSFER_TYPE_UPLOAD_DIRECTORY` | the transfer is an upload of a directory |
| `S3_TRANSFER_TYPE_COPY` | the transfer is a copy of a file from one S3 path to another S3 path |
| `S3_TRANSFER_TYPE_COPY_DIRECTORY` | the transfer is a copy of a directory from one S3 path to another S3 path |

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2590.
