# s3.transfer.finished()

## Syntax:
`function string s3.transfer.finished( long transfer )`

## Description
Returns true if an S3 transfer has finished. A transfer is finished if the status is one of the following:

- `S3_TRANSFER_STATUS_CANCELED`

- `S3_TRANSFER_STATUS_TIMED_OUT`

- `S3_TRANSFER_STATUS_FAILED`

- `S3_TRANSFER_STATUS_COMPLETED`

## Arguments
| | | |
|---|---|---|
| `long` | `transfer` |  an s3.transfer object  |

## Return values
| | |
|---|---|
| `true` | the transfer has finished |
| `false` | the transfer is not yet finished |

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2590.
