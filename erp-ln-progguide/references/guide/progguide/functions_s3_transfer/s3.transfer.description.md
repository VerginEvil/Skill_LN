# s3.transfer.description()

## Syntax:
`function string s3.transfer.description( long transfer )`

## Description
Returns the description of an s3.transfer object.
E.g. for an s3.transfer object of type `S3_TRANSFER_TYPE_DOWNLOAD`, the description is a string like: "Downloading object from %1$s/%2$s". The description can be used e.g. when showing a progress indicator.

## Arguments
| | | |
|---|---|---|
| `long` | `transfer` |  an s3.transfer object  |

## Return values
a transfer description

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2590.
