# s3.transfer.delete()

## Syntax:
`function void s3.transfer.delete( long transfer )`

## Description
Deletes an s3.transfer object. If the transfer is still in progress it will be canceled first.

## Arguments
| | | |
|---|---|---|
| `long` | `transfer` |  an s3.transfer object; is set to `0` after the s3.transfer object has been deleted  |

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2590.
