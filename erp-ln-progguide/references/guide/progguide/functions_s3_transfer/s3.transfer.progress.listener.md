# s3.transfer.progress.listener()

## Syntax:
`function long s3.transfer.progress.listener( )`

## Description
Returns a progress listener for S3 transfers. This listener shows progress using a progress indicator.
Note  If a progress indicator already exists, this progress listener will not report any progress.

## Return values
a progress listener object

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2590.
