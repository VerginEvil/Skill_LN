# s3.transfer.start.upload.directory()

## Syntax:
`function long s3.transfer.start.upload.directory( const string s3.directory, const string directory, long progress.listener, long timeout.ms )`

## Description
Initiates an upload of a directory from the file system to S3. While the transfer is busy, the program can continue doing other things. It is also possible to start other transfers.
This function returns an s3.transfer object. Use [s3.transfer.status](s3.transfer.status.md) to get the transfer status. Use [s3.transfer.result](s3.transfer.result.md) to get the transfer result. You can also use convenience function [s3.transfer.finished](s3.transfer.finished.md) which returns `true` when the transfer has finished.
Important  Do not forget to delete the transfer object with [s3.transfer.delete()](s3.transfer.delete.md)
Example:
```

long    transfer
long    result

|* start uploading a directory structure from $BSE/appdata/docs to S3
transfer = s3.transfer.start.upload.directory(
                "${AWS_S3}/documents/",
                path.combine(bse.appdata.dir$(), "docs"),
                s3.transfer.progress.listener(),
                10000)    |* timeout in millis

|* do other things while transer has not yet finished
while not s3.transfer.finished(transfer)
        |* do other things...
endwhile

|* check transfer status to see if it succeeded
if s3.transfer.status(transfer) <> S3_TRANSFER_STATUS_COMPLETED then
        |* check result and handle error
        result = s3.transfer.result(transfer)
        |* ...
endif

|* do not forget to delete the transfer object
s3.transfer.delete(transfer)
```

## Arguments
| | | |
|---|---|---|
| `const string` | `s3.directory` |  the path of the destination S3 directory  |
| `const string` | `directory` |  the path of the directory to upload  |
| `long` | `progress.listener` |  a progress listener object; you can use e.g. [s3.transfer.progress.listener](s3.transfer.progress.listener.md), which shows progress information in a progress window; specify `0` if no progress must be reported  |
| `long` | `timeout.ms` |  the timeout in milliseconds after which the transfer is canceled; if not specified, or if less than or equal to 0, the transfer never times out  |

## Return values
| | |
|---|---|
| `<> 0` | an s3.transfer object; use this to keep track of the transfer status |
| `0` | A precondition was not met |

This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2590.
