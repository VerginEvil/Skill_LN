# s3.transfer.transferred.bytes()

## Syntax:
`function long s3.transfer.transferred.bytes( long transfer )`

## Description
Returns total number of bytes transferred of an s3.transfer object.

## Arguments
| | | |
|---|---|---|
| `long` | `transfer` |  an s3.transfer object  |

## Return values
the total number of bytes transferred

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2590.
