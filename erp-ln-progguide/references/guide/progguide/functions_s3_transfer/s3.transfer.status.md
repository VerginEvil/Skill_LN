# s3.transfer.status()

## Syntax:
`function long s3.transfer.status( long transfer )`

## Description
Returns the status of an s3.transfer object.
In case the transfer status is `S3_TRANSFER_STATUS_CANCELED`, `S3_TRANSFER_STATUS_TIMED_OUT` or `S3_TRANSFER_STATUS_FAILED`, you can also check the result of a transfer by calling [s3.transfer.result](s3.transfer.result.md).

## Arguments
| | | |
|---|---|---|
| `long` | `transfer` |  an s3.transfer object  |

## Return values
| | |
|---|---|
| `S3_TRANSFER_STATUS_NOT_STARTED` | the transfer has not yet started |
| `S3_TRANSFER_STATUS_IN_PROGRESS` | the transfer is in progress |
| `S3_TRANSFER_STATUS_CANCELED` | the transfer was canceled by e.g. a user |
| `S3_TRANSFER_STATUS_TIMED_OUT` | the transfer timed out |
| `S3_TRANSFER_STATUS_FAILED` | the transfer failed, e.g. because a path is invalid |
| `S3_TRANSFER_STATUS_COMPLETED` | the transfer was succesful |
| `S3_TRANSFER_STATUS_UNKNOWN` | unknown transfer state; it is assumed the transfer failed |

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2590.
