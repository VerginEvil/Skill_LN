# s3.transfer.wait.until.finished()

## Syntax:
`function [long] s3.transfer.wait.until.finished( long transfer )`

## Description
Waits for the S3 transfer to be finished. This function also returns in case the S3 transfer is canceled, timed out, or failed.
If a progress listener was specified when the transfer was started, progress will be reported as well.

## Arguments
| | | |
|---|---|---|
| `long` | `transfer` |  an s3.transfer object  |

## Return values
optional, the S3 transfer status, see [s3.transfer.status](s3.transfer.status.md)

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2590.
