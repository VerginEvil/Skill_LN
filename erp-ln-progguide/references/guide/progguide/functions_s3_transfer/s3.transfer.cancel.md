# s3.transfer.cancel()

## Syntax:
`function [long] s3.transfer.cancel( long transfer )`

## Description
Initiates a cancel of an S3 transfer and optionally returns its current status.

- A cancel does not attempt to clean up any files that have already been transferred

- It may take a (little) while before the transfer is actually canceled. You can call [s3.transfer.status](s3.transfer.status.md) or [s3.transfer.finished](s3.transfer.finished.md) e.g. every second to see if the S3 transfer has already been canceled. You can also use convenience function [s3.transfer.wait.until.finished](s3.transfer.wait.until.finished.md) which blocks the current program until the S3 transfer is canceled.

## Arguments
| | | |
|---|---|---|
| `long` | `transfer` |  an s3.transfer object  |

## Return values
optional, the S3 transfer status, see [s3.transfer.status](s3.transfer.status.md)

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2590.
