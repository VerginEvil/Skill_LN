# s3.transfer.percentage.complete()

## Syntax:
`function double s3.transfer.percentage.complete( long transfer )`

## Description
Returns the percentage complete of an s3.transfer object.

## Arguments
| | | |
|---|---|---|
| `long` | `transfer` |  an s3.transfer object  |

## Return values
the percentage complete as a double

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2590.
