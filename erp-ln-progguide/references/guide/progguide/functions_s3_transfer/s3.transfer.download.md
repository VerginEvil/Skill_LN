# s3.transfer.download()

## Syntax:
`function long s3.transfer.download( const string s3.file, const string file, long progress.listener, long timeout.ms )`

## Description
Downloads a file from S3 to the file system. This function waits until the transfer is finished.
Example:
```

long    result

|* download a file from S3 to $BSE/appdata/docs
result = s3.transfer.download(
                "${AWS_S3}/documents/expenses.csv",
                path.combine(bse.appdata.dir$(), "docs", "expenses.csv"),
                s3.transfer.progress.listener(),
                10000)    |* timeout in millis

|* check result
if result <> 0 then
        if result = -99 then
                |* transfer was aborted by the user
        else
                |* handle error; a DAL error message has already been set
        endif
endif
```

## Arguments
| | | |
|---|---|---|
| `const string` | `s3.file` |  the path of the S3 file to download  |
| `const string` | `file` |  the path of the destination file; this cannot be a directory  |
| `long` | `progress.listener` |  a progress listener object; you can use e.g. [s3.transfer.progress.listener](s3.transfer.progress.listener.md), which shows progress information in a progress window; specify `0` if no progress must be reported  |
| `long` | `timeout.ms` |  the timeout in milliseconds after which the transfer is canceled; if not specified, or if less than or equal to 0, the transfer never times out  |

## Return values
| | |
|---|---|
| `0` | No error |
| `-11` | the bshell version is too old |
| `-12` | the transfer was started but failed |
| `-13` | the transfer was started but timed out |
| `-21` | the source file or directory does not exist |
| `-22` | the user has no access to the source file or directory |
| `-23` | the path of the source file is a directory |
| `-31` | the directory of the target file does not exist |
| `-32` | the user has no access to the target file or directory |
| `-33` | the path of the target file is a directory |
| `-99` | the transfer was started but was aborted by the user |
In case of an error, except error `-99`, a DAL error message has been set.

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2590.
