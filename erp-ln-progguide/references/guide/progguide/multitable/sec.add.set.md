# sec.add.set()

## Syntax:
`function void sec.add.set( long id )`

## Description
Perform an `add.set` on a secondary table.

## Arguments
| | | |
|---|---|---|
| `long` | `id` |  The ID of the secondary table.This ID was obtained via a call to [sec.add.table()](sec.add.table.md).  |

## Context
This function is implemented in the 4GL Engine and can be used in 4GL script types. This function is available from [TIV](../tiv/tiv_overview.md) level 1075.
