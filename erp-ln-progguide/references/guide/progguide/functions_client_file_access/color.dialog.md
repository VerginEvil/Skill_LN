# color.dialog()

## Syntax:
`#include <bic_desktop>`
`function void color.dialog( ref long io.color )`

## Description
This shows a color selection dialog, to allow the user to select a color. The selected color is then reported back to the application when the dialog box exits.

## Arguments
| | | |
|---|---|---|
| `ref long` | `io.color` |  Input/Output argument which contains the RGB value of the selected color.  |

## Context
This function is implemented in the 4GL Engine and can be used in all script types.
