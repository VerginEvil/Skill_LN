# 308 ESQLINDEXOUTOFDIMS - Array column index out of range
308 ESQLINDEXOUTOFDIMS - Array column index out of range
| |
|---|
| *Description:* |
| This error occurs if an array column is indexed outside its dimensions. Note This error applies only to Infor Enterprise Server releases. |
| *Solution:* |
| Ensure the index stays within the array columns dimensions. |
