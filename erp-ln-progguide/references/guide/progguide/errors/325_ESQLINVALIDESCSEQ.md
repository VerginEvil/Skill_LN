# 325 ESQLINVALIDESCSEQ - Invalid escape sequence
325 ESQLINVALIDESCSEQ - Invalid escape sequence
| |
|---|
| *Description:* |
| This error occurs if an ansi LIKE pattern contains a wrong ESCAPE sequence. Note This error applies only to Infor Enterprise Server releases. |
| *Solution:* |
| It can be solved by assuring that the escape character in the like pattern is always followed by '_', '%' or the escape character. |
