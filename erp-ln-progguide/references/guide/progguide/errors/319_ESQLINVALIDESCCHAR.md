# 319 ESQLINVALIDESCCHAR - Invalid escape character
319 ESQLINVALIDESCCHAR - Invalid escape character
| |
|---|
| *Description:* |
| This error occurs if an ansi LIKE predicate contains a wrong ESCAPE character. Note This error applies only to Infor Enterprise Server releases. |
| *Solution:* |
| It can be solved by assuring that the escape value has a length of 1. |
