# 217 ECORRUPTROLE - Role file is corrupt
217 ECORRUPTROLE - Role file is corrupt
| |
|---|
| *Description:* |
| This error indicates that one of the database role files is corrupt. The syntax of the role may not be correct or it may contain a reference to a table or column that does not exist. See the log file for more detailed information. Note This error applies only to Infor Enterprise Server releases. |
| *Solution:* |
| Contact Infor support. |
