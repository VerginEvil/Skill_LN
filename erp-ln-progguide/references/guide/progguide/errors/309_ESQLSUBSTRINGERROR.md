# 309 ESQLSUBSTRINGERROR - SQL invalid substring length
309 ESQLSUBSTRINGERROR - SQL invalid substring length
| |
|---|
| *Description:* |
| This error indicates incorrect usage of the substring operator. It occurs if the specified length is less than zero. Note This error applies only to Infor Enterprise Server releases. |
| *Solution:* |
| Ensure a correct substring length is used. |
