# 306 ESQLDIVBYZERO - Division by zero
306 ESQLDIVBYZERO - Division by zero
| |
|---|
| *Description:* |
| This error occurs when in an SQL statement an attempt is made to make a division by zero. Note This error applies only to Infor Enterprise Server releases. |
| *Solution:* |
| The SQL statement may be incorrect, or there may be an issue with the data. Either correct the SQL statement of correct the data. |
