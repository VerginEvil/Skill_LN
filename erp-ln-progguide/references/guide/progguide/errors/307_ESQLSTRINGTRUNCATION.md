# 307 ESQLSTRINGTRUNCATION - SQL String truncation
307 ESQLSTRINGTRUNCATION - SQL String truncation
| |
|---|
| *Description:* |
| This error occurs if a string operation (string concatenation for example) results in a string that is too long for the SQL processor (more than 2048 bytes). Note This error applies only to Infor Enterprise Server releases. |
| *Solution:* |
| Identify the string which becomes too long and prevent it from becoming too long. |
