# soap.init()

## Syntax:
`function long soap.init( )`

## Description
Initializes the SOAP client.

## Return values
| | |
|---|---|
| 0 | On success |
| <> 0 | In case of an error |

## Context
This function is implemented in the 4GL Engine and can be used in all script types.
