# on.change.check()

## Syntax:
`function void on.change.check( string variable )`

## Description
This starts the checking mechanism by setting a checkpoint for the specified variable. The current value of the variable becomes the checkpoint value.

## Arguments
| | | |
|---|---|---|
| `string` | `variable` |  |

## Context
This function is implemented in the porting set and can be used in all script types.
