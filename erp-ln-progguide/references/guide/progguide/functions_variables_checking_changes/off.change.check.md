# off.change.check()

## Syntax:
`function void off.change.check( string variable )`

## Description
This switches off the checking mechanism for the specified variable. Changes to the variable are no longer monitored by the checking mechanism.

## Arguments
| | | |
|---|---|---|
| `string` | `variable` |  |

## Context
This function is implemented in the porting set and can be used in all script types.
