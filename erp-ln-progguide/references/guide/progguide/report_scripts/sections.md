# Report script sections
A report script consists of one or more event sections in which you program actions to be performed at particular states of execution of the report to which the report script is linked. The statements programmed in a report script section consist of a combination of [3GL programming language features: overview](../3gl_features/overview.md) and [Report script functions](functions_in_report_scripts.md).
Report scripts support the following event sections:
- [Program sections (report scripts)](program_sections.md)
- [Report sections (report scripts)](report_sections.md)
- [Text field sections (report scripts)](text_field_sections_report_scripts.md)
