# http.response.headerlist()

## Syntax:
`#include <bic_httpclt>`
`function long http.response.headerlist( long response )`

## Description
Returns the list of HTTP headers received from the server.

## Arguments
| | | |
|---|---|---|
| `long` | `response` |  an http.response object  |

## Return values
an http.headerlist object

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2120.
