# http.oauth1params.delete()

## Syntax:
`#include <bic_httpclt>`
`function void http.oauth1params.delete( long oauth1params )`

## Description
Deletes an http.oauth1params object.

## Arguments
| | | |
|---|---|---|
| `long` | `oauth1params` |  an http.oauth1params object  |

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2340.

## Preconditions
- the passed id must be a valid http.oauth1params object
