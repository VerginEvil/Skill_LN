# http.oauth2params.delete()

## Syntax:
`#include <bic_httpclt>`
`function void http.oauth2params.delete( long oauth2params )`

## Description
Deletes an http.oauth2params object.

## Arguments
| | | |
|---|---|---|
| `long` | `oauth2params` |  an http.oauth2params object  |

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2470.

## Preconditions
- the passed id must be a valid http.oauth2params object
