# http.mimepartlist.new()

## Syntax:
`#include <bic_httpclt>`
`function long http.mimepartlist.new( )`

## Description
Constructs a new http.mimepartlist object.

## Return values
a new http.mimepartlist object, or 0 in case of an error

## Context
This function is implemented in the 4GL Tools and can be used in all script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2220.
