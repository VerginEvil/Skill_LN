# map.is.active()

## Syntax:
`function boolean map.is.active( )`

## Description
Tells whether the Map Workbench is running for the current session.

## Return values
| | |
|---|---|
| true | The Map Workbench is (still) running. |
| false | The Map Workbench is not running for this session. |

## Context
This function is implemented in the 4GL Engine and can be used in 3GL script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2590.
