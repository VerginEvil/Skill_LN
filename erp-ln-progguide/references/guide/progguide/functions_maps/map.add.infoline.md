# map.add.infoline()

## Syntax:
`function void map.add.infoline( long infoid, string label, string value )`

## Description
Add a new line to an info object.

## Arguments
| | | |
|---|---|---|
| `long` | `infoid` |  An info object id returned by function [map.add.info()](map.add.info.md).  |
| `string` | `label` |  The label string which will be shown in the left part of a line.  |
| `string` | `value` |  The value string which will be shown in the right part of a line.  |

## Context
This function is implemented in the 4GL Engine and can be used in 3GL script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2340.
