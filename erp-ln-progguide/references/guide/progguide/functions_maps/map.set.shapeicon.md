# map.set.shapeicon()

## Syntax:
`function void map.set.shapeicon( long rpid, string image )`

## Description
Show an icon instead of a sequence number in this route point.

## Arguments
| | | |
|---|---|---|
| `long` | `rpid` |  A route point object id returned by function [map.add.point()](map.add.point.md).  |
| `string` | `image` |  The additional file name or the full path name of the image file. If there are forward or backward slashes in the image argument it is assumed to be a full path name.  |

## Context
This function is implemented in the 4GL Engine and can be used in 3GL script types. This function is available from [TIV](../tiv/tiv_overview.md) level 2420.
