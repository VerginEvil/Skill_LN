# Maps Workbench overview

## Introduction
A generic Maps Workbench is delivered with Enterprise Server. Through this Workbench a geographical map can be shown. On this map application defined route points and a route can be drawn. The full functionality is only available when Microsoft Bing Maps is configured as a Maps provider. When using "Open Street Maps", only route points will be shown on the map and no route lines. Configuration of a Maps provider must be done through session: "Map Providers (ttaad7132m000)"

## Show a Map from 4GL-Sessions
A set of functions is available which can be used from 4GL-Sessions to define a set of route points and to show or refresh the map. These functions and related constants can be used by including <bic_maps>.
