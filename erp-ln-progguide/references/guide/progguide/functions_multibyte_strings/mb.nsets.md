# mb.nsets()

## Syntax:
`function long mb.nsets( )`

## Description
This function returns the number of TSS character sets currently defined. This is useful for retrieving character set information using [mb.set.info()](mb.set.info.md).

## Context
This function is implemented in the porting set and can be used in all script types.

## Example
See [mb.set.info()](mb.set.info.md).
