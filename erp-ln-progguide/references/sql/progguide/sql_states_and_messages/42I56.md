# 42I56 - Subquery table selected for update
An SQL statement contains a subquery and one of the tables in the FROM clause of that subquery is marked FOR UPDATE.

## Example
```

select empno, firstnme
from   dbtst120
where  empno in ( select mgrno
                  from   dbtst100 for update )
```
A table in a subquery cannot be marked FOR UPDATE. This query will cause the error:
SQLState 42I56: Subquery table 'dbtst100' selected for update
