# 42I83 - RETRY clause not allowed in grouped query
A grouped query contains an ORDER BY clause with a RETRY clause.

## Example
```

select edlevel, max(salary)
from   dbtst120
group  by edlevel
order  by 1 with retry
```
The query is a grouped query, because it contains a GROUP BY clause. A grouped query may not contain a RETRY clause. This query will cause the error:
SQLState 42I83: RETRY clause not allowed in grouped query
