# 42I26 - Combined expression in IN predicate
An SQL statement contains an IN predicate and the left operand of this IN predicate is an explicit row value constructor (also called a Combined)

## Example 1
```

select firstnme
from   dbtst120
where  { empno } IN ( 100, 200, 300 )
```
This query causes the error:
SQLState 42I26: Combined expression in IN predicate
