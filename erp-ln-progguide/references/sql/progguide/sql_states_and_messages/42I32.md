# 42I32 - Compnr specification in HAVING clause
An SQL statement contains a company number specification in a HAVING clause.

## Example
```

select max(salary)
from   dbtst120
group  by edlevel
having company_nr = 100
```
Company number specifications are only allowed in the WHERE clause. This query causes the error:
SQLState 42I32: Compnr specification in HAVING clause
