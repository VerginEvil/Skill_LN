# 42I22 - The ORDER BY number is an invalid number
An SQL statement contains an ORDER BY clause and this ORDER BY clause contains a number that is either less than 1 or greater than the number of selected columns.

## Example
```

select firstnme, lastname
from   dbtst120
order  by 3
```
The ORDER BY clause specifies column number three, but the query only selects two columns. This query will cause the error:
SQLState 42I22: The ORDER BY number 3 is an invalid number. It must be between 1 and 2
