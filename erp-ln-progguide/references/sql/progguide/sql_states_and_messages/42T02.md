# 42T02 - Incompatible types for BETWEEN
An SQL statement contains a BETWEEN predicate and the operands of this BETWEEN predicate do not have comparable datatypes.

## Example
```

select empno
from   dbtst120
where  workdept between 1 and 10
```
Column workdept is of type string. String and integer are not comparable datatypes. This query will cause the error:
SQLState 42T02: Incompatible types for BETWEEN operator
